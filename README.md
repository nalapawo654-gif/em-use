# EM Use · 额度小鱼缸

Windows / macOS 桌面悬浮额度应用，支持「额度小鱼缸」「充气牛马」和「林间海狸鼠」。鱼缸通过蓝色水体的水位、牛马通过饱满程度、海狸鼠通过精神状态与树木形态展示 AI 云平台的每日剩余额度。所有桌宠均采用透明桌面呈现，常规操作默认隐藏、悬停显示，支持角色互动与换装。

## 桌宠开发规范

新增或修改桌宠前，阅读 [桌宠基础交互规范](docs/desktop-pet-interaction-standard.md)。显隐、拖窗、缩放、面板、额度、设置和托盘行为必须遵循该规范；互动种类、名称、手势、道具和完成条件由每只桌宠独立设计，不要求共享“清洁”等固定动作。规范包含新增接入清单、验收要求和现有实现差异。

## 开发

Node.js 24，npm。

```bash
npm ci
npm run desktop
```

`npm run desktop` 启动 Vite 和 Electron。修改 Electron 代码后重新启动。`npm run dev` 只启动浏览器外观预览，预览会明确标注演示数据，不会连接真实账号。

```bash
npm test
npm run typecheck
npm run build
npm run pack
npm run dist
```

## 使用

1. 鼠标移到鱼缸上，点击“登录 AI 云平台”，在应用打开的官方窗口扫码或确认授权。
2. 应用只观察自己的登录窗口向 AI 云平台发出的请求，获取 `X-Dong-Auth`、`X-Dong-User`、`X-Dong-Client`。
3. 通过真实额度接口验证后，登录窗口关闭，鱼缸显示剩余额度。
4. 正常情况下每 60 秒查询一次。失败时指数退避，睡眠暂停，唤醒重新查询。
5. 每日北京时间 00:00 重新查询。只有服务端费用日期进入新一天才恢复有效显示，不在本机假设满额。
6. 托盘可恢复悬浮窗、关闭鼠标穿透、打开设置或退出。关闭悬浮窗会收起到托盘。

金额来自 `GET https://aihub.eastmoney.com/ai-cloud-hub/coding-plan/usage`，使用 `dailyCostLimit` 与 `currentDayCost` 计算。费用可能延迟数分钟；费用时间超过 15 分钟、或已有结果超过 3 分钟未成功查询时标记过期。

## 窗口操作

- 按住鱼缸主体任意位置拖动；轻点鱼或宝箱仍可互动。清洁模式优先擦拭，结束后恢复拖窗。
- 悬停时拖四角自由缩放，保持鱼缸比例。也可以按住 Ctrl / ⌘ 滚轮，或在设置中拖动大小滑杆。
- 支持 180–800 px；不超过当前屏幕工作区。标准、紧凑、迷你为快捷预设，大小与位置保存在本机。
- 操作面板打开期间保持可见；移开鼠标后常规工具自动隐藏，键盘聚焦时也会显示。
- 夜间采用独立灯光素材，全部水位保持蓝色。设置可选白天、夜晚或跟随昼夜。

## 安全与数据

- 登录网页关闭 Node，启用 sandbox/contextIsolation；主进程只向官方固定额度地址发送三个鉴权头，不带 Cookie，不允许接口重定向。
- 验证通过的鉴权头使用 Electron safeStorage 加密后保存到本机 userData。系统加密不可用时只保留在内存。
- 登录网页使用内存 Session；退出账号清除登录缓存和加密凭据。
- 凭据不会暴露给应用界面、写入日志或上传 GitHub。不要把本机 userData、Cookie 或请求头值提交到仓库。
- 设置与窗口位置存放本机；无需额外后端。

## GitHub 构建

推送 `main`、PR 或手动运行 **Build desktop apps**：

- Ubuntu 检查类型、测试、构建。
- Windows x64 生成 NSIS EXE。
- macOS arm64 / x64 生成 DMG 与 ZIP。
- 产物在 Actions Artifacts 保存 14 天。
- 推送与 package.json 版本相同的 `v*` 标签，全部平台成功后创建 GitHub Release 草稿及 SHA256 校验文件。

当前工作流为 **未签名内部预览包**。正式分发前配置 Apple Developer ID 签名、公证和 Windows 代码签名。没有在客户端嵌入 GitHub Token，也没有自动下载安装更新。

## 验收边界

纯数据测试覆盖真实字段结构、额度超额、非法数据、北京跨日、旧数据、鉴权字段完整性。真实扫码登录需要人工完成，跨平台交互需要实际 Windows / macOS 安装验证；构建成功不代表这些边界已经通过。

## v0.2.0 互动

- **换装**：工具栏“换装”或设置中的“小鱼衣橱”，选择原生小鱼、水手帽、皇冠、领结。装扮跟随小鱼游动，保存到本机设置。
- **宝箱**：直接点击缸底宝箱，或“玩耍 → 打开宝箱”，经历晃动、开启、珍珠浮起后自动恢复。
- **躲猫猫**：“玩耍 → 躲猫猫”，小鱼游进石头洞，点击洞穴找回；无人操作时会自行出来。
- **擦鱼缸**：点击“清洁”，按住鼠标在玻璃上拖动海绵。按实际擦过的区域计算进度，也可点击“自动擦拭”。重复擦同一点不会直接完成。
- **喂食**：食物下落，小鱼追逐进食；轻柔模式减少移动。
- Esc 或玩法提示旁的关闭按钮可结束当前玩法。右键鱼缸也可打开玩法菜单；迷你窗口通过顶部“玩耍”按钮进入。
- 所有互动均为本机视觉效果，不消耗或增加 API 额度。截图功能位于“玩耍”菜单中。

## 林间海狸鼠

- 六档额度姿态与树木状态，透明窗口和 hover 操作沿用公共规范。
- 角色专属梳毛、喂面、喝水、送木头；更多玩法支持摸摸、丢球、收集树叶、小鸟来访和休息。
- 五种天气主题装扮、本机趣味对白、营地与标语保存；桌面端可拍照并保存分享图。
- 天气装扮不代表实时天气，趣味对白不连接外部聊天服务，互动不会改变真实额度。
- 角色设计与行为见 [林间海狸鼠](docs/woodland-beaver.md)，验证与边界见 [海狸鼠验收记录](docs/design-qa-beaver-2026-09-10.md)。

# 0.4.2 · 咚咚自动登录正式发布

## 修复的发布问题

新仓库的 `main` 已包含 `1919258`（咚咚自动登录与手动账户切换）和 `66ae333`（首次启动默认选择咚咚），但之前同步的 `v0.4.1` 仍指向更早的 `fa95836`。从 0.4.1 静态发布包安装时不会获得这套功能。

0.4.2 从包含上述两个提交的最新代码发布，并提升客户端与更新清单版本，让 0.4.1 能识别新版本。旧标签保留原位置。下载页同步说明咚咚连接与旧手动账户的升级行为，源码链接指向当前发布仓库 `nalapawo654-gif/em-use`。

## 使用方式

- 本机咚咚已登录时，首次启动 EM Use 默认尝试自动连接并同步额度。
- 设置的“账户与额度”和托盘提供“使用咚咚账户”“手动登录其他账户”。
- 已有手动账户升级后保持手动模式；需要使用咚咚时主动切换一次，后续启动遵循保存的选择。
- 主动退出后暂停自动连接；自动模式切号、失效重试与手动模式的隔离规则见[公共交互规范](../../docs/desktop-pet-interaction-standard.md)。

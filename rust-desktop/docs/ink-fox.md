# 水墨小狐

角色参考：仓库根目录 `小狐狸.png`。本次接入 Rust/Tauri 产品，Electron 目录继续保留作迁移对照。公共交互遵循 [桌宠基础交互规范](../../docs/desktop-pet-interaction-standard.md)。

## 角色与额度

白狐、墨色大尾巴、朱砂眉心；原生透明窗口仅保留角色、小印章和额度。浏览器额外展示宣纸风格介绍与状态样例。正常待机持续呼吸、独立尾巴摆动及闭眼眨眼；中低档呼吸，零额度墨团轻轻起伏。页面隐藏暂停动画；轻柔模式保留缓慢呼吸并停止摆尾、眨眼与飞蝶，系统减少动态偏好同样处理。

| 平台剩余 | 姿态 | 台词 |
| --- | --- | --- |
| >60% | 蓬松白狐与浓墨尾巴 | 元气满满！ |
| >20% 且 ≤60% | 墨色变淡的坐姿 | 还有点墨～ |
| >15% 且 ≤20% | 伏在前爪上 | 别看，省着呢。 |
| ≤15% | 有眼睛的小墨团 | 不是消失，是留白。 |
| 未知 / 非有限数值 | 中性坐姿、额度显示 — | 墨有多少，等一等就知道。 |

状态说明继承共享账户的 ready/stale/expired/resetting 等语义；仅 ready/stale 可显示可用额度。任何互动都不改变金额。真实额度从零回升时播放一次墨尾舒展，随后回到当前额度对应姿态。

## 日常仪态（2026-09-12 补充）

以优雅、克制为目标：轻柔呼吸作为底层，每次只出现一个自发小动作；第一次在 1.8–3.2 秒后出现，之后间隔 6.5–13 秒，避免连续重复。动作首尾缓入缓出，抬爪动作包含抬起、轻拂两次、停留、放下。

- 缓缓眨眼：稍快合眼，慢慢睁开，保留原本的水墨眼形。
- 抬爪拂耳：独立前肢从胸前抬起，碰到耳根轻拂，头部自然侧低，随后收爪。
- 侧首听风：耳尖微偏，头部轻侧，身体与脚保持安定。
- 轻嗅空气：鼻尖短暂探动，动作幅度小于侧首。
- 舒卷尾尖：尾尖慢慢舒展后归位，不大幅甩尾。
- 垂眸小憩：微微低头合眼，短暂休息后回到原姿态。

满额/未知坐姿支持全部动作；中额保持原本闭眼坐姿，不借日常动作变回满额；低额只做眨眼、听风、轻嗅和小憩；零额仅墨团眼睛缓眨和小憩。手动玩法、面板、拖窗、轻柔模式、系统减少动态、页面隐藏均让日常动作让位；切换额度/配色/场景时清理定时器与渲染帧。预览衣橱和状态卡不启动自发动作。

## 独立玩法

所有玩法是轻点触发的短动画，不占用拖动手势，不设计双击、擦拭或进度条。主体和尾部命中区使用 `.scene-hit`，达到 5 px 后交给共享拖窗。重复动作重新开始，新动作替换旧动作；Esc、结束按钮均立即取消；切换桌宠、卸载、窗口失焦清除临时动作。

| 动作 | 入口 / 手势 | 道具与反馈 | 完成 / 恢复 |
| --- | --- | --- | --- |
| 摸摸尾巴 | 尾部轻点、工具栏、玩法 | 尾巴轻摆、眯眼，朱砂「阅」印 | 2.8 秒自动结束 |
| 递张纸条 | 工具栏、玩法 | 出现「加班」纸条，尾巴一甩涂成一团墨 | 4.2 秒自动结束 |
| 追一只蝶 | 主体轻点、工具栏、玩法 | 朱红蝶绕着狐耳飞，狐狸轻轻探身 | 4.8 秒自动结束 |
| 舒展墨尾 | 玩法、真实额度从零回升 | 一圈墨色舒展、短暂立起，结束后服从真实额度 | 3.2 秒自动结束 |
| 留白一会 | 玩法 | 缩成墨团、眼睛轻动，保留「回来」按钮 | 持续，主体轻点 / 回来 / Esc 恢复 |

面板由单个枚举管理，玩法、配色、额度详情互斥；容器处理 Esc。面板与当前动作反馈使用共享 `data-pet-gesture` 排除拖窗。常规操作在 hover、键盘 focus-visible 或面板打开时显示；隐藏同时禁用命中，动作期间隐藏缩放柄。180 px 时面板滚动、关闭按钮固定可达，基础入口由顶部玩法保留。

## 配色与素材

独立 `foxSkin`：水墨（classic）、青墨（jade）、暖墨（sepia）。保留白狐与朱砂，仅温和改变整体墨色气氛。通过共享 settings 校验 / Rust 合同保存，旧配置默认 classic。接入 App、浏览器场景选择、设置、托盘。

素材由内置 imagegen 按参考图生成。首版带棋盘格，因此再次使用 imagegen 改为纯绿色底；运行时一次性抠色成透明分层，保留白色毛发。提示词与素材路径见 [生成记录](ink-fox-generation.md)。层次：独立尾巴、睁眼主体、闭眼主体、中额坐姿、低额伏姿、零额墨团。真实文本、金额和道具反馈由 Vue 渲染。

# EM Use v0.4.7

2026-09-15。发布仓库：`nalapawo654-gif/em-use`。沿用现有更新签名密钥与 Windows x64、macOS ARM64、macOS Intel 打包流程。

## 本次更新

- 11 只桌宠接入本机咚咚当日日程。默认提前 5 分钟提醒，支持查看今日安排、知道了、稍后提醒，以及标题和地点隐私设置。
- 各角色独立日历物料与提醒台词，统一复用日程调度、去重和窗口服务。面板、消息、互动和拖窗按状态避让，保留原图集、动作及手势。
- 日程按北京时间当天同步；切号、改期、缓存失效、跨日及休眠恢复由共享服务处理，不修改咚咚日程或参会状态。
- 消息展示群聊 / 联系人标题，按不透明会话 ID 归并，并保留隐私遮罩。
- 主动登录与平台入口复用内置官方登录窗口，保留显式咚咚登录选择。

## 验证与发布边界

日程源码与浏览器证据见 [实现说明](calendar-implementation.md)、[九宠验收记录](design/nine-calendar-v1/README.md)。本地已通过类型、构建、153+5 前端 / 脚本测试、34 项 Rust 测试（3 项既有忽略）及素材基线校验。浏览器覆盖 432 组九宠布局、45 次换装、88 次菜单操作、900 帧待机和 18 次提醒响应。

本次按用户要求仅触发标签打包并确认任务启动，不持续跟踪构建完成。安装包、更新签名及静态服务器整包以 `v0.4.7` Actions 的实际结果为准。真实账户提醒、跨平台原生交互及安装升级不能因构建启动而视为验收通过。

# EM Use v0.5.2

2026-10-14。发布仓库：`nalapawo654-gif/em-use`。

用户可见说明以 [release-notes/0.5.2.md](../release-notes/0.5.2.md) 为唯一来源。此版只发布已有修复，不包含新玩法。

- Windows 咚咚安装资源优先从正在运行的进程目录发现，复用会话、消息模块和主动唤起的共享路径逻辑。用户配置与消息目录仍遵循现有来源，不移动或写入咚咚数据。
- 原生消息气泡及消息卡显示前校验桌宠可见性；收起使旧弹窗请求失效，最终显示与收起在 UI 线程串行。窗口构建保留在异步线程，避免 Windows WebView2 同步创建死锁。
- 收起按钮与原生关闭共用窗口清理，保留未读与手动查看入口。公共规则见 [桌宠基础交互规范](../../docs/desktop-pet-interaction-standard.md)，实现见 [消息说明](message-notices-implementation.md)。

## 验证与发布边界

功能修改已在本地 macOS 编译并通过 68 项 Rust 测试，7 项真实账户 / 本地数据测试明确忽略。新增测试覆盖自定义安装目录发现与合成会话读取、隐藏窗口拦截、收起后恢复时旧请求失效。Windows 专用 D/E 盘路径测试由标签工作流执行。

正式安装包、签名和静态服务器整包以 `v0.5.2` 标签工作流最终结果为准。未将单元测试或打包成功视为 Windows 实机验收：D 盘真实咚咚连接、隐藏期间接收新消息及安装后的自动升级仍需新包实测。

只生成 Windows x64 和 macOS ARM64 包，不构建 Intel Mac。Windows 沿用既有更新签名密钥；Mac 保留手动 DMG 替换。静态服务器需另行上传：先上传本版安装包、素材和页面，最后替换 `em-use/stable/latest.json`，保留旧版本目录。

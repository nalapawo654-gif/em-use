# 斯卡蒂 · 月汐

依据用户提供的 `斯卡蒂.png` 与 `斯卡蒂1.png`：银白长发、红瞳、月海意象、黑红花饰及夜影黑猫。实现位于 Rust / Tauri 桌面项目；公共操作遵循 [桌宠基础交互规范](../../docs/desktop-pet-interaction-standard.md)，继续复用账户、额度、窗口手势和设置桥接。

## 双形态、衣装与兵装

- 御姐 / 萝莉可切换，使用两套不同身体比例的实际画稿。
- 每种形态分别有夜海之誓、纯白圣歌、暗夜魅影、樱落和服、星穹战姬、休闲居家六套完整衣装，共十二套。两种形态独立记住衣装；旧 `skadiSkin` 保留为 Q 版选择，新增 `skadiAdultSkin`、`skadiForm`、`skadiWeapon` 均有默认值、共享校验与 Rust 契约。
- 六件武器：赤渊长剑、月蚀镰刀、星眠法杖、冰霜双刃、血月弓、灵蝶浮刃。通过顶部武器库或公共设置切换，换衣服、换形态不重置装备。
- **常态手持武器**。依据用户追加要求，已取消早期的角色旁悬浮方案。武器的握柄对应人物手掌点，人物与武器先在同一 512px 坐标系合成，再统一执行呼吸、发梢与步行动画；手掌局部盖在握柄上。双刃拆成两件，一手一把。睡姿收在身前，坐姿随手放在膝前。
- 长剑斩弧、镰刀月轮、法杖星阵、双刃冰晶、弓箭雨、浮刃蝶群分别实现。技能时握柄为转动支点，武器不会绕角色独立漂浮。装备不烘焙进服装图，因此更换后不会残留旧武器。

## 额度与公共行为

额度 >60% 为月光充盈，>20% 为潮声渐缓，>15% 为夜色渐深，≤15% 为静候新潮；未知显示 —，保持中性陪伴。光环与文案反映额度状态，低额与零额使用坐姿；角色、武器与核心额度始终可见。沿用 ready / stale / expired / resetting 等共享语义，互动不改变真实额度。

常规操作区只在悬停、键盘可见焦点或打开面板时出现。衣橱、武器库、玩法、额度详情互斥且可关闭；动作反馈和结束按钮持续可达。复用 `useWindowGestures` 的拖窗阈值、拖后点击抑制、四角缩放及修饰键滚轮。失焦、隐藏和场景切换清理动作，卸载停止监听与绘制。

## 专属互动

所有玩法可从更多玩法进入；前三项还在常用工具栏。头部轻点摸头，身体轻点陪工作（睡姿时唤醒），黑猫轻点逗猫。短动作到期自动恢复，持续动作保留结束入口，Esc 或新动作可取消 / 替换。重入重新计时。

- 旧 V1 人物资产保留为历史素材，但当前人物加载路径统一为 `assets/skadi/v2/`。哈希、尺寸和来源登记于 `docs/native-assets.json`。

# 11 只桌宠 · 咚咚新消息设计需求

2026-09-14 · 绘图版。目标：咚咚收到消息时，桌宠用自己的动作提醒，用户看摘要后打开咚咚处理。本文保留绘图目标；当前已实现交互、素材差异与验证范围见 [消息实现说明](message-notices-implementation.md)。

**账户前提：**额度可用扫码 / 手动账户 B，也可跟随本机咚咚 A；消息始终属于当前本机咚咚 A。UI 分别显示两个账户，换额度不换消息；咚咚换号清理旧消息。

## 1. 所有角色共用的交互

**平时 → 来消息并做短动作 → 气泡 → 点击展开 / 自动收起 → 小道具入口。**

| 状态 | 画面与操作 |
| --- | --- |
| 平时 | 正常桌宠，不增加常驻大底板；没有新提醒时不显示数量角标。 |
| 新消息 | 角色做一次约 1–2 秒的动作，出现两行气泡：`咚咚 · 张三` + 一行摘要；右上角 `×`。不抢焦点，不循环闪烁，默认不新增提示音。 |
| 自动收起 | 气泡 5 秒后收起，悬停暂停倒计时；点击 `×` 立即收起。保留专属小道具与数量角标，例如 `3`，超过 99 显示 `99+`。 |
| 展开查看 | 点击气泡或小道具，打开消息卡片；含来源、发送人 / 群名、时间、摘要、`打开咚咚 ↗`、`收起`、右上角 `×`。不自动消失；Esc 可关闭。 |
| 多条消息 | 同一会话合并，例如 `张三 · 3 条新提醒`，气泡只显示最新摘要。展开按会话排列，最多露出 3 行，其余滚动；点击某行查看该会话的新提醒列表，并可返回会话列表。新消息只更新列表，不打断当前阅读。 |
| 暂停提醒 | 小道具旁出现静音标记，暂停期间不播放动作、不弹气泡；点击可查看已有提醒或恢复。恢复后不集中补弹。 |

**数量含义：**角标是本工具“尚未查看的新提醒”，不是咚咚总未读数。自动收起、`×`、Esc 不清除计数；展开后实际展示的消息记为本工具已查看，对应角标减少。两者都不更改咚咚已读状态。切换角色沿用同一份提醒，不重复播放。

**让位规则：**拖动、玩法、衣橱、额度详情或更新面板正在使用时，只记录新提醒，结束后合并提示。消息卡片打开时暂停主要玩法和缩放，按钮不触发拖窗。与版本更新同来时不叠两张卡：消息用“咚咚 + 对话气泡”，版本更新用“新版本 + 版本号”，入口可区分。

## 2. 每只桌宠怎么表现

各角色复用上面的字段和按钮。以下是角色动作与皮肤，不要把装饰文字替代真实发送人和消息内容。

| 角色 | 新消息动作 / 表情 | 收起后的小入口 | 气泡与展开卡片 |
| --- | --- | --- | --- |
| **额度小鱼缸** | 小鱼游近水面，顶起装着小信的透明气泡，吐两颗小泡后恢复游动。 | 水面边的小信气泡，角标贴外侧。 | 淡海蓝半透明边缘、白色阅读区；气泡尾朝水面，不遮水位和额度牌。 |
| **充气牛马** | 停一下，耳朵竖起，抬蹄把挂在身侧的邮包向前递。 | 身侧小邮包，翻盖带对话符号。 | 米白纸条与浅蓝布袋边，少量缝线；轻松、有工作伙伴的感觉。 |
| **林间海狸鼠** | 抬头看向用户，双爪举起夹着便笺的小树枝，尾巴轻拍一次。 | 座旁树枝便笺夹。 | 苔绿细边、浅木色夹子、暖白纸张；树叶只作角落点缀。 |
| **仓鼠动力机房** | 空闲跑轮短暂停下，仓鼠双爪举起齿轮封口的小信封，眨眼后恢复。 | 跑轮侧面的齿轮信封，角标挂右上。 | 奶油信纸、黄铜细边与小回形针；沿用已出的“仓鼠递信”设计。 |
| **修仙渡劫事务所** | 传音纸鹤飞到肩侧，角色侧目点头；纸鹤展开一角。 | 肩侧悬停的小纸鹤。 | 淡宣纸、朱砂小印、细卷轴边；正文仍用清晰横排字体。 |
| **健身电池人** | 胸前通信小灯亮一下，抬手示意“收到”，弹出小对话屏。 | 身侧通信小屏；勿放在真实电量格上。 | 深绿外边、浅色阅读区、细电路线；不把消息数量画成电量。 |
| **肥嘟嘟** | 从奶茶杯套抽出爱心便笺，递向用户，露出开心表情。 | 奶茶杯侧露出的便笺角。 | 奶油白、蜜桃粉、圆角贴纸；杯形只体现在边角，正文区域保持规整。 |
| **水墨小狐** | 竖耳回头，尾尖托起一封素白小笺，一滴墨轻轻散开。 | 尾尖旁的折叠小笺。 | 宣纸白、墨灰文字、少量朱红；墨迹不穿过正文。 |
| **破产招财猫** | 招财爪摇一次小铃，另一爪递出红边便笺；表情稍微精神一点。 | 座旁小铃与便笺。 | 暖白卡片、红色窄边、少量金线；不铺大面积金光。铃声仅用动作表达。 |
| **摸鱼小恐龙** | 从身侧拿出小手机，看一眼后转向用户；屏幕亮起对话符号。 | 身侧小手机，屏幕带数量角标。 | 薄荷绿便笺、奶油白阅读区、小圆角；动作后手机收回，不持续刷屏。 |
| **斯卡蒂 · 月汐** | 夜影黑猫抬爪推来月牙封蜡信，人物侧目微笑；月光轻亮一次。 | 夜影旁的小月牙信封。 | 月蓝与银色细边、少量星点；保留衣装和武器，Q 版 / 成人形态共用布局。 |

低额度、休息状态只让小道具动一下，不强迫角色站起、跑动或恢复精神。换装保留原服装。每张动作图检查肢体数量，持信动作不能多出手脚。

## 3. 卡片内容样例

```text
咚咚消息                         ×
张三                         10:32
接口已经更新，方便的时候
帮忙看一下。

[ 打开咚咚 ↗ ]            [ 收起 ]
```

- 群消息：同一会话 ID 合成一张卡，顶部只显示一次群名及提醒总数，下面以轻量时间线列出发送人、时间和正文，最新在前。不同会话即使同名也不合并。确认收到 @我 时在对应消息加小标签，不使用持续闪烁。
- 多会话：每个会话一行，显示名称、最新发送人 / 摘要、提醒总数和新提醒数。进入会话后顶部可返回列表；其他会话到达不打断阅读。底部固定保留“打开咚咚”和“收起”。
- 隐藏正文：显示 `你收到了一条新消息`，包括气泡和卡片；不因悬停意外露出正文。
- 图片 / 文件：显示 `[图片]` / `[文件] 需求说明.pdf`；不自动展开图片或下载附件。长姓名、群名和文件名省略，正文可滚动。
- `打开咚咚` 第一版打开应用；暂不画“直接进入该聊天”或“快捷回复”。
- 设置页预留：提醒开关、显示 / 隐藏正文、暂停 30 分钟 / 1 小时 / 恢复、遵循咚咚免打扰；状态为“正常接收 / 等待咚咚连接 / 当前版本暂不支持”。异常不反复弹气泡。

## 4. 绘图范围与尺寸

**每只角色画 3 张主状态：新消息气泡、展开卡片、收起后角标。** 动作再给“起始 → 举起道具 → 恢复”3 个关键姿态；统一补一套多会话列表、隐私模式、静音、连接异常即可，无需 11 套重复画。

- 以 **440 × 440** 桌宠为标准，补 **300** 紧凑与 **190 / 180** 迷你示例。消息区域不遮角色脸、核心额度和关闭按钮；超出屏幕时向内调整。
- 迷你状态只放小入口、数量与短气泡，点击打开独立的小消息面板；不要把正文和两个按钮硬缩进 180px，也不因此放大桌宠。
- 气泡优先置于头顶或道具附近，展开卡片可向外侧打开；它是临时浮层，角色周围保持透明，不增加常驻背景板。
- 每种卡片补日 / 夜配色、悬停 / 键盘焦点样式。轻柔模式保留静态道具与角标，省略动作、粒子和闪光。
- **分层交付：**角色姿态、信件 / 手机等道具、特效、气泡底、卡片底分别输出；姓名、正文、时间、数字与按钮文字独立可编辑，不能烘焙进角色图片。

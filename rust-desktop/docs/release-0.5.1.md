# EM Use v0.5.1

2026-10-13。发布仓库：`nalapawo654-gif/em-use`。

用户可见说明以 [release-notes/0.5.1.md](../release-notes/0.5.1.md) 为唯一来源，随包写入静态更新清单。

- Windows 新增独立河床桌面世界，复用设置和托盘，支持主屏壁纸、鼠标互动、投喂和暂停。实现与来源见 [桌面世界说明](desktop-world-riverbed.md)。
- 新增原创 EM Use 启动片头，支持跳过、设置开关、减少动态效果、开机自启动跳过与超时兜底。生命周期及权限边界见 [启动片头说明](startup-intro.md)。
- 停止 Intel Mac 构建及下载入口，保留 Windows x64 和 macOS ARM64。

## 验证与边界

功能提交已通过 177 项 TypeScript 测试、12 项脚本测试、64 项 Rust 测试，7 项真实账户或本地数据测试明确忽略。类型检查、生产构建和迁移对比检查通过；此前 Windows 和 macOS ARM64 的 GitHub Actions 安装包构建成功。正式版本以 `v0.5.1` 标签工作流的最终结果为准。

浏览器已验证河床渲染、鼠标、投喂、暂停及错误处理，并验证启动片头的播放、正常结束、Esc / 按钮跳过、减少动态效果、加载失败、紧凑尺寸及解码资源释放。浏览器中的原生事件使用测试桥接，不能代替原生窗口验收。

远程 Windows 实机已观察到河床位于桌面图标之后。Intel UHD 630 上运行河床时 GPU 占用曾达 96%–100%；用户暂停后观察到约 13%，但背景同时恢复为原壁纸，因此暂停保留画面的原生行为仍待确认。本版未声称完成低性能显卡优化。

启动片头的 Windows / macOS 原生显示、焦点和窗口切换，以及正式安装后的升级流程、真实账户验证尚未验收。

## 发布方式

标签工作流生成 Windows x64 安装包及更新签名、macOS ARM64 DMG 和静态服务器整包。Windows 复用现有更新签名密钥；该签名不等同于 Windows Authenticode 签名。Mac 保留手动 DMG 替换。

静态服务器需另行上传：保留旧版本，先上传 `em-use/releases/0.5.1/`、`em-use/site-assets/0.5.1/` 和下载页面，最后更新 `em-use/stable/latest.json`。生成包不代表服务器已部署或客户端已升级。

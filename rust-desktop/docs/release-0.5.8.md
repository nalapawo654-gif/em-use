# EM Use v0.5.8 · 纸箱寄居蟹

2026-10-24。基于已发布 v0.5.7，保留桌角神射手与已有角色，新增纸箱寄居蟹。用户可见说明见 [版本说明](../release-notes/0.5.8.md)，玩法与实现边界见 [接入记录](design/hermit-crab-v1/implementation.md)。

下载页扩展为 15 只伙伴，补齐寄居蟹与投篮桌宠的普通 / Codex 觉醒展示。新图采用实际浏览器演示截图 PNG，其余展示图继续使用 WebP。支持混合图片扩展名的分发与校验。

## 发布前验证

- 独立发布目录：229 项前端测试和 12 项发布脚本测试通过；共享契约、类型检查和生产构建通过。主 JS 包仍有超过 500 kB 的体积提示。
- 77 个绘制 / 动作 / 手势文件的基线校验通过；56 张旧素材逐像素一致，106 张 Tauri 专用素材哈希 / 尺寸检查通过（包含 4 张寄居蟹图集）。
- 浏览器：已检查寄居蟹普通 / 觉醒、保留的投篮场景、下载页 15 只角色列表、新展示图切换及 v0.5.8 下载链接。
- Windows 与 macOS ARM64 安装包只由标签工作流构建，CI 执行各平台 Rust 测试和 macOS 签名检查。构建结果以对应运行记录为准。
- 未进行真实账户、两端安装升级、系统拖窗 / 跨屏 / 托盘验收。打包通过不代表这些层面已验证。
- 内网静态站需先上传本版资源与页面，最后替换更新清单；生成静态分发包不等于内网部署完成。

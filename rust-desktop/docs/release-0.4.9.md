# EM Use v0.4.9

2026-09-20。发布仓库：`nalapawo654-gif/em-use`。

## 更新内容

用户可见说明以 [release-notes/0.4.9.md](../release-notes/0.4.9.md) 为唯一来源，打包时写入 `stable/latest.json` 与版本目录 `version.json`。更新来信和设置显示“本次更新”；CI 检查对应版本说明，避免继续展示通用占位文案。

本版包含桌宠内最近会话、完整文字与图文阅读、图片预览、本机只读消息查询缓存优化、会话直达、联系人搜索和仅限指定私聊的限时自动回复，以及已查看提醒残留修复。详情见 [消息实现说明](message-notices-implementation.md)。

Mac 保留手动检查与 DMG 下载替换；Windows 保留自动更新与现有签名密钥。服务端已读回执不等同于咚咚本机红点已同步，不能宣称自动清除咚咚本机未读已解决。

## 验证边界

- 源码与测试：157 项 TypeScript、10 项发布脚本、57 项 Rust 测试通过；7 项真实账户测试明确忽略。类型检查、行为契约、生产前端构建及物料交互 parity 通过。
- 浏览器：使用本版完整说明验证肥嘟嘟更新卡的“本次更新”、滚动区域和 Mac“前往下载”按钮；更新清单测试确认说明完整写入两个清单。
- 原生与真实账户：之前已验证 macOS 文字与图片阅读、服务端回执、修复后客户端重启；咚咚本机红点、会话跳转最终落点、Windows 原生使用及安装器升级仍须分别验证。
- 发布仅确认标签对应的 Actions 已启动，不持续监听打包结束。三平台安装包与静态服务器整包以本次工作流最终产物为准。

静态服务仍需手动上传：保留旧版本，先上传版本目录与页面，最后更新 `em-use/stable/latest.json`，客户端才会收到本版和更新说明。

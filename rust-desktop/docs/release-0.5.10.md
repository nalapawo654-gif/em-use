# EM Use 0.5.10 发布检查

2026-10-27。基于已发布 v0.5.9 整合当前工作区的额度变装小人、项目协作窗口、自建协作服务及随包 MCP。保留 v0.5.7–0.5.9 的篮球、寄居蟹、投篮小鸡、下载页与资源清单修复；不提交本机缓存、凭据、测试数据库和运行输出。

## 本轮验证

- 应用 TypeScript 测试 243 项、脚本测试 13 项通过。
- 契约生成、Vue 类型检查、Vite 构建通过；主入口仍有大分块提示。
- 渲染/手势基线校验通过；128 项原生资源哈希和 56 张旧图集逐像素校验通过。
- macOS Rust 测试 76 项通过、8 项按现有条件忽略。编译及测试不等于实际窗口或安装验收。
- 协作服务在新建的隔离 PostgreSQL 测试库通过 4 项集成测试，包含鉴权、房间、任务、许可、越权、租约、取消和成果验收路径。
- MCP 2 项单元测试、1 项真实 MCP/CLI 子进程与本机服务往返测试通过。上述测试结束后删除本轮新建数据库，不改变此前的联调库。
- macOS arm64 release MCP 编译通过，二进制架构、可执行性和 `--version` 检查通过。
- 浏览器复核新角色未知态、四档切换、Codex 演示额度与觉醒展示，以及设置中的项目协作入口和独立页面。演示额度不是真实账户；浏览器不证明原生窗口操作。浏览器唯一资源错误为预览站 favicon 404。
- 下载页增加第 16 个伙伴及普通/觉醒图片；静态分发脚本与签名清单测试通过。

## 发布及验收边界

版本文件统一为 0.5.10；标签 v0.5.10 触发 GitHub Actions 的 verify、Windows x64、macOS arm64 和静态服务器分发包。最终结果以对应提交的 CI 为准，不能以本文件代替远端成功记录。

本轮未在本机生成分发安装包、未替换正式安装应用、未连接真实额度账户、未向内网静态服务器部署。项目协作依赖另行部署并升级的自建服务，应用安装包只随附 MCP 客户端。此前 macOS QA 与真实宿主记录见 [项目协作验证](project-collaboration-desktop-v1.md)，不等同于本次正式包的安装/升级验证。Windows 凭据库、实际安装后的宿主接入、macOS 升级后的钥匙串授权连续性仍待实机验证。

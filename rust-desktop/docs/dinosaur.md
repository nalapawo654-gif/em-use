# 摸鱼小恐龙

遵循 [桌宠基础交互规范](../../docs/desktop-pet-interaction-standard.md)。参考根目录 `小恐龙.png`：薄荷绿软陶恐龙、奶油肚皮、橙色背刺，保持两只脚与完整尾巴。透明桌面上只呈现角色、台词与真实额度，浏览器提供独立展示页。

## 角色与额度

额度 >80% 元气站立；>60% 抱奶茶；>20% 趴橘色软垫；>15% 无力趴平；≤15% 休息闭眼。未知与非有限数字保持中性站姿，数字显示 —，不冒充满额。金额、日期与错误状态来自共享 bridge；stale 显示待更新，过期/跨日/无权限保持各自状态。

四种独立保存的身体配色：经典绿、樱花粉、奶龙黄、酷炭黑。仅重着色绿色身体，保留奶油肚皮、橙色背刺、眼睛和道具。支持昼夜、轻柔及系统减少动态效果。

## 互动定义

所有入口均为按钮；主体轻点摸头，右键/玩法按钮打开更多玩法；不设计双击、拖擦或进度条。公共 5px 拖窗判断、拖后抑制点击和四角缩放复用 useWindowGestures。

| 名称 | 入口与反馈 | 完成条件 |
| --- | --- | --- |
| 摸摸小脑袋 | 主体、玩法；眯眼举爪、爱心回应 | 2.4 秒自动恢复 |
| 奶茶摸鱼 | 快捷、玩法；抱杯吸珍珠 | 4.5 秒自动恢复 |
| 咔嚓小饼干 | 快捷、玩法；双手捧饼干、小幅咀嚼 | 4 秒自动恢复 |

| 抱紧小软垫 | 玩法；趴在橘色软垫上 | 持续，结束按钮恢复 |

新动作替换旧动作并重置计时；短动作在隐藏/失焦时收束；卸载清理定时器、媒体监听与公共指针手势。持续状态始终保留结束入口；容器内 Esc 关闭面板并取消动作。玩法、衣橱、额度详情互斥，面板悬停外仍保留，面板与动作期间隐藏缩放手柄。互动均不改变真实 API 额度。

## 日常动画扩展（2026-09-12）

随机待机加入：长出小翅膀飞一圈、偷偷刷手机、打哈欠、左顾右盼、举爪伸懒腰。使用独立头、身体、左右手、左右翅膀与手机层；翼根拍打、飞行闭合轨迹、手机取出/滑动/收起和头手关节分别动画。动作结束回到当前额度姿态。手机只是本地动画道具，不读取真实手机或任何应用内容。

日常动作首轮在 4–7 秒后出现，随后间隔 9–17 秒，同一动作不连续重复；高额度/未知可飞行、玩手机，低额度以打哈欠/观察为主，零额度保持趴平。自动动作不抢占手动互动、面板、拖窗；页面隐藏、切换场景、失焦、轻柔模式与系统减少动态效果时停止调度并清理动画。容器 Esc 可取消，活动期间保留结束按钮。更多玩法及预览展示允许主动观看这五种动作。

飞行动画范围限制在宠物容器中，不移动操作系统窗口。动画期间命中控件跟随角色平移与缩放。持续工作/睡眠保持其原姿势，不被随机动画打断。

# EM Use v0.4.6

2026-09-14。发布仓库：`nalapawo654-gif/em-use`，沿用现有更新签名密钥。

## 本次更新

- 修正消息卡片收到短暂失焦就立即关闭的逻辑。卡片首次激活后才启用失焦关闭；等待 200 ms 并核实窗口状态，重新聚焦或销毁会取消旧检查。
- Windows 对比整个前台窗口，避免将 WebView2 内部焦点变化当作切换到其他窗口。关闭按钮、收起和 Esc 保持可用。
- 道具打开消息卡片期间忽略重复点击；道具和气泡保留创建、定位、显示或激活失败的具体原因，允许重试。

## 验证与发布边界

- 本地 macOS Rust 测试 30 项通过，2 项真实账户测试未运行；包含 4 项焦点状态回归。契约、类型检查、前端构建通过。
- 海狸鼠浏览器演示验证点击开卡、重复点击合并、失败原因、重试、收起后重开、键盘及 Esc、咚咚桥接调用、气泡错误提示，无页面脚本错误。
- GitHub 标签构建执行版本、素材、前端及各平台 Rust 检查，生成 Windows x64、macOS ARM64、macOS Intel 安装包和静态服务器整包。实际结果以 `v0.4.6` 对应 Actions 为准。
- 尚未在 Windows 真机复现或验收本次焦点修复；打包成功不代表真实账户、原生消息交互或安装升级通过。

静态服务手动上传时保留历史目录，先上传 releases / site-assets 及页面，最后更新 `em-use/stable/latest.json`。

# 咚咚消息提醒 · 实现说明

2026-09-14。当前为本地源码实现，尚未发布安装包。

## 账户规则

| 变化 | 额度 | 消息 |
| --- | --- | --- |
| 手动 / 扫码登录 B，本机咚咚是 A | B | A |
| 切换或退出额度账户 | 按额度操作变化 | A 的监听和提醒保留 |
| 本机咚咚 A 换成 C | 手动 B 不变；跟随模式按原额度逻辑更新 | 清除 A 的旧卡片和角标，建立 C 的新基线 |
| 咚咚退出登录或退出运行 | 手动额度不受影响 | 清理旧提醒，显示等待连接 |

设置中分别显示两个账户；消息页提供当前咚咚姓名与账户标识。两者不一致不会报错，也不会自动替用户切换额度。

## 当前交互

- 11 只桌宠各有专属道具：水泡信、邮包、树叶信、齿轮信、纸鹤、通信屏、奶茶便笺、水墨信、金铃、手机、月牙信。原角色、服装和额度素材保留；目前由道具完成短动作，角色举手、眨眼等新动画姿态仍以绘图需求为后续目标。
- 新消息显示发送人和单行摘要；约 5 秒后收起，悬停 / 键盘可见焦点暂停计时。迷你尺寸只显示单行来源提示。点击 `×` 或自动收起不减角标。
- 点击道具或气泡打开桌宠旁的独立卡片；屏幕边缘换侧放置。`×`、收起、Esc 或切换到其他窗口关闭；不改变桌宠尺寸。
- 多会话按会话标识分组，实际进入并看到某条提醒时才减少本工具角标；会话列表本身不把内容算作已查看。新会话不会打断当前阅读。只保留当前会话期间最近 100 条提醒，重启不恢复提醒历史。
- 支持隐藏姓名 / 正文、暂停 30 分钟 / 1 小时、恢复提醒、遵循咚咚免打扰。隐藏正文在原生 IPC 发出前完成；暂停不补弹。图片、语音、视频和文件仅用文字摘要表示。
- 打开咚咚只打开应用，不自动定位聊天、不回复、不发送已读回执。正在玩法、拖动、衣橱、额度详情或版本更新中时暂缓提示；切换桌宠不重播旧提醒。

## 原生接收

`src-tauri/src/message_source.rs` 只读打开当前咚咚加密消息库；从本机安装包取得匹配的 WASM 模块，在限制内存和运算量的解释器中使用。SQLite 只读连接并开启 `query_only`，不写入消息、附件或登录配置，不需要 Node 常驻进程。

每秒检查进程、配置摘要和数据库版本；配置不变时复用已解析会话，数据库未变时不查询消息，失败间隔 5 秒重试。初次连接、换号和断线重连建立新基线，不把已有历史消息作为新提醒。每批最多读 200 行并继续取后续批次；过滤自己发送、过旧、已读、撤回、隐藏和免打扰记录。

`messages.rs` 独立维护来源代次、去重和提醒队列；不访问额度 token、登录模式或额度请求代次。换号会更换代次，拒绝旧界面提交的查看记录；查询完成后再次核对配置，丢弃切换期间的结果。密钥、原始消息 ID 和会话凭据不传给界面，不记录消息正文日志。

## 验证与边界

- **源码 / 测试：**149 个 TypeScript 测试、5 个站点脚本测试、24 个 Rust 测试通过；类型检查、前端构建、原生测试编译通过。新增原生测试覆盖真实加密格式的临时库、只读拒写、超过 200 条的继续接收、过滤 / 免打扰元数据、已读清理、换号与旧回调拒绝、隐私输出和独立卡片边界。
- **浏览器：**11 个角色 × 440 / 300 / 190 共 33 组入口、气泡、独立卡片、关闭及本工具计数检查；另测多会话、隐藏正文、夜间、悬停计时、玩法暂缓、更新互斥和额度账户切换。脚本为 `scripts/message-notice-qa.cjs`、`scripts/message-notice-flow-qa.cjs`；测试页使用演示数据。
- **真实账户：**本机 macOS 咚咚 3.4.1 的消息库已由本次 Rust 接收代码成功只读打开。此前研究脚本实际捕获过测试消息，详见 [验证记录](../../docs/research/dongdong-message-reception-2026-09-14.md)。本次未把旧脚本接收成功当作新原生界面端到端成功。
- **待真机验收：**macOS 原生窗口侧边定位 / 失焦关闭 / 托盘入口及新代码实时消息到卡片链路；真实私聊 / 群聊 / @我、已读 / 撤回同步与免打扰；Windows 运行、安装和消息库兼容性。其他咚咚版本尚未验证。

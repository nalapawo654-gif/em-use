# 咚咚日程 · 十一位伙伴

2026-09-15。用户选定牛马方案 3，并继续授权小鱼缸及剩余九只桌宠，接入 Tauri 应用；未改旧 Electron 的桌宠实现。

## 使用

本机咚咚已登录时自动同步当天个人日程，约每分钟更新。设置 → 咚咚日程可关闭、隐藏标题地点、选择提前 1/5/10/15 分钟、启用开始时再提醒。默认提前 5 分钟，系统通知及开始时再提醒关闭。

点击各角色的日历小道具，或托盘「今日日程」查看安排。气泡显示真实剩余时间、标题和地点。「知道了」取消这一项本工具提醒；「2 分钟后提醒」最晚延到开始时间。同时间多项放在同一张可滚动卡片。当天已过的计划时段可折叠展开，不推断参会或完成状态。全天安排不主动提醒。

隐藏桌宠或穿透时，不强行唤起桌宠；可自行开启系统通知。系统权限与免打扰仍由操作系统控制。请求失败显示状态与上次同步时间，禁止将失败当作“没有安排”。

## 物料及避让

使用 [方案 3](design/buddy-calendar-v1/03-grass-flip-calendar.png) 的蜂蜜木架、奶油纸页、黄铜环和蓝色包边，制作 [独立原图](../public/assets/buddy/calendar-stand.png)。生成稿的牛马不用于运行；原骨骼、皮肤、贴图、动作和草地原样保留。运行时去除绿底，数字及图标由界面叠加，详见 [素材生产记录](design/buddy-calendar-v1/asset-production.md)。

按动作安全区将日历从概念稿立柱右前方移到左侧。440/300px 道具占窗口 20%，180/190px 占 18%，位于 y=72%。最小点击区约 32px，日历数字为环境提示，清晰事项在独立卡片阅读。原有木牌、充气泵、水桶、草料、消息邮包和缩放柄不移动。

局部短摇动用于到点提示，轻柔模式静态显示；本版没有纸页撕下或连续翻页特效，避免占用已有动作。展开覆盖面板和拖窗时暂藏日历，玩法中保留入口但暂停道具动效。点击日历不调用 act、不取消清洁、不启动摸摸或拖窗。

## 数据与调度

`calendar.rs` 独立维护读取状态及原生每秒调度。`dongdong::calendar_day` 复用本机登录解析，只 GET calendars/v2/personalCalendar 的北京时间当天范围，不读取日程描述，不发送或变更日程。HTTP 请求禁重定向、响应上限 4MB、最多 2000 项。时间解析失败保留旧结果并标记待更新。

咚咚源变动触发重读；异步请求完成后核对源标记，换号及登录失效清空旧内容。去重键包含账户、日程 ID 与开始时间，改期形成新提醒；令牌轮换不重置同账户去重。重启只恢复哈希键、确认/已提示标记和稍后时间，无标题、地点或凭据。15 分钟过期缓存不主动提醒，午夜清理，休眠恢复先刷新，只补当前开始后 5 分钟内的事项。

日程窗口沿用消息窗口的屏幕边缘布局及原生失焦守卫。提醒不抢焦点，查看卡可以聚焦；消息与日程面板互斥，当前阅读及拖动优先，待可用再提醒。共享窗口手势、设置校验与账户服务仍为原实现。

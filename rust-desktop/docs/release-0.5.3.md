# EM Use v0.5.3

2026-10-16。发布仓库：`nalapawo654-gif/em-use`。用户可见说明见 [release-notes/0.5.3.md](../release-notes/0.5.3.md)。

本版包含本机 Codex 实时额度监控、共享来源切换 / 详情 / 提醒，以及 13 种桌宠全衣橱觉醒造型与专属变身。实现边界见 [Codex 额度](codex-quota.md) 和 [觉醒形态](codex-evolution.md)。下载页补齐 13 只伙伴，提供原有 / Codex 觉醒造型预览、本次更新、连接指南与准确的形态阈值说明。

发布校验保留旧 Electron 原始素材与手势基线，仅登记本次明确修改的 19 个渲染 / 展示集成文件；101 张 Tauri 专用素材（含 44 张觉醒图集）记录尺寸和 SHA-256。原有 56 张无损素材继续逐像素比较。

## 验证与交付边界

- 源码 / 测试：207 项前端测试、12 项发布脚本测试通过；契约、类型检查、生产构建、版本一致性、渲染基线和素材完整性通过。构建仍有主 chunk 大于 500 kB 的提示。
- Rust：74 项通过，8 项真实账户 / 本地数据测试忽略。本次发版没有重新运行真实账户测试，未读取或保存用户对话与凭据。
- 浏览器：下载页 13 种原有造型和 13 种觉醒造型切换、图片解码、Windows / Mac 版本链接、FAQ、390 / 320 px 无横向溢出通过。桌宠新展示图取自模拟桥接的 80% 演示额度。截图位于忽略的 `output/playwright/`。
- 原生桌面：先前 macOS 调试启动记录见功能文档；本轮不将源码或浏览器检查视为 Windows 安装、系统托盘、透明窗口、休眠恢复或完整账户验收。
- 安装包：由 `v0.5.3` 标签工作流构建 Windows x64 与 macOS ARM64，结果以该工作流为准。Windows 沿用更新签名，Mac 保留手动 DMG 替换。
- 静态站：工作流生成包含新页面、展示素材、安装包与更新清单的服务器整包。生成整包不等于已部署到内网服务器；上传时先合并本版资源及页面，最后替换 `em-use/stable/latest.json`，保留旧版本目录。

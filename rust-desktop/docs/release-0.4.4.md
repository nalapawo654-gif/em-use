# EM Use v0.4.4

2026-09-14。发布仓库：`nalapawo654-gif/em-use`；从包含以下全部功能的同一提交创建 `v0.4.4` 标签，沿用现有签名密钥和三平台打包流程。

## 本次更新

- 11 只桌宠的专属咚咚消息道具、短气泡、角标与独立消息卡片；多会话、隐藏正文、暂停及免打扰设置。
- 消息始终跟随本机咚咚，额度可以使用另一手动 / 扫码账户；切换额度不影响消息，咚咚换号清理旧提醒。
- 自动检查更新、角色专属更新来信、稍后记忆、下载进度和失败重试；明确点击后才安装重启。
- 消息与更新提示互相让位，并避让玩法和窗口手势；迷你模式保留可读小入口。
- 下载说明页扩展至 11 只桌宠，沿用网站目录合并覆盖与签名清单发布方式。

## 发布前验证

源码、单元测试、前端构建和浏览器交互已验证；新增通知接入的旧角色容器使用经审阅的双侧哈希基线，原图、动画状态机和窗口手势仍受原有校验覆盖。构建状态以此次标签对应 GitHub Actions 为准。

本机 macOS 咚咚 3.4.1 真实消息库已完成 Rust 只读打开验证；Windows 消息兼容性、原生消息到卡片完整链路，以及实际安装升级仍需真机验收。详情见 [消息实现说明](message-notices-implementation.md) 和 [更新提示说明](pet-update-notices.md)。

产物包括 Windows x64、macOS Apple Silicon、macOS Intel 安装包及静态服务器整包。手动上传时先传完整 releases / site-assets，再传页面，最后更新 `em-use/stable/latest.json`；保留旧版本目录。

# EM Use 启动片头

2026-10-13。参考 dsh-boot-animation 的短视频播放与释放思路，重新编写 Tauri / Vue 接入和原创 EM Use 片头；没有引入 DSH 插件、代码或品牌视频。

## 体验

手动启动 → 光点汇成小鱼标志 → EM USE 字样亮起 → 片头淡出 → 桌宠在原来位置出现。
片头为 3 秒、1280×720 / 30 fps 的本地静音 MP4（约 140 KiB），独立 720×405 无边框窗口，支持跳过按钮和 Esc。不启用全屏，不增加持续 WebGL 渲染。
默认开启，在「设置 → 桌面行为 → 启动片头」可关闭；轻柔模式、系统减少动态效果、带 `--autostart` 的开机启动跳过。启动插件复用原设置与服务，并刷新已开启的自启动注册参数；升级后第一次由旧注册项启动可能还会播放，随后注册项已更新。
托盘恢复、单实例唤回及切换宠物不重播。初始片头是公共品牌动画，最终显示的是用户保存的桌宠与装扮。

## 生命周期

- `startup.rs` 用进程内状态协调片头结束和 Vue 挂载，不等待真实账户、消息、日程、额度请求。
- `startup_event` 分别验证 `startup` / `/startup.html` 和 `widget` / `/index.html`。片头只允许报告播放 / 结束，不调用通用 desktop API，也不接收共享状态。
- 加载视频数据后才显示片头窗口并允许 Esc。播放器完成 / 跳过 / 失败后淡出 240 ms，移除视频与 source 的 src 并调用 load 释放解码器；再向原生报告结束。
- 播放器最长 4.4 秒，原生另设 6 秒看门狗。即使 HTML、JS、视频或 IPC 失败也能释放片头并显示桌宠。
- 窗口销毁、收起、重复启动 / 托盘唤回以及延迟回调均有一次性保护。首次移交后不会因迟到的超时重新打开被收起的宠物。
- 视频和原始生成脚本在 `public/startup/`、`scripts/render-startup.py`。构建直接打包素材，不在安装或启动时生成视频。
- 浏览器 `/startup.html` 结束后显示明确的预览结束页和重播按钮；原生结束时销毁整个窗口。

## 验证

- 前端类型与生产构建、共享代码 / 资源一致性校验通过。
- 177 项 TypeScript 测试、12 项脚本测试通过；含设置迁移、幂等结束、隐藏窗口初始化、跳过 / Esc / source 错误、超时、轻柔模式与媒体清理。
- macOS 编译和 Rust 测试：64 项通过，7 项既有真实账户 / 本机数据测试默认忽略；含两种回调顺序、迟到回调、看门狗和 IPC 来源隔离。
- 浏览器 Chrome 实际 H.264 播放通过，720×405 和 360×240 画面已查看；正常结束、Esc、按钮跳过、资源失败、减少动态效果、解码源清理通过，无页面 JS 异常。模拟原生 IPC 仅收到 playing / finish，不代表原生桌面验收。
- Windows / macOS 原生显示、焦点、首次启动衔接、自启动与 GPU 占用仍待安装包实测；未做真实账户验证。打包成功不能替代这些验证。

# Windows 桌面世界 · 河床

## 范围

独立于现有 13 只桌宠的动态壁纸。第一期仅 Windows、主显示器、一个河床场景。
设置 → 桌面世界与托盘 → 桌面世界 · 河床提供开启、暂停 / 继续、投喂和失败重载。
默认关闭，开启和暂停偏好保存到现有 `preferences.json`，开机启动使用原来的应用级开关。
桌宠可以同时显示；关闭 / 收起桌宠不关闭壁纸，关闭壁纸不退出桌宠，退出 EM Use 一并退出。

## 场景与交互

- 来源：Deskworlds，固定提交 `42ad88c98b394efddb071016f2df40d3c2032c96`。
- 本地 Three.js / WebGL2 河床、水草、鱼群和食物行为。原场景不重画，运行采用 Balanced / 30 fps 上限。
- 原生场景不接收直接点击；Windows 宿主每 50 ms 最多采样一次鼠标，只有坐标变化且鼠标位于桌面区域时才转发。经过其他应用、桌宠、任务栏或移出主屏发送离开事件。
- 投喂一小撮鱼食，鱼群自动接近；属于短暂环境互动，无需进度条或结束按钮。只在运行状态接收，一次请求等待一次渲染层确认；暂停 / 加载 / 轻柔模式 / 错误期间拒绝，超时不自动重发。
- 暂停保留画面，停止模拟和输入。轻柔模式也暂停，但不覆盖用户保存的暂停偏好。没有额度分档、装扮、账户或日程的独立副本。
- 浏览器地址 `/world.html?preview=1` 提供明确标记的预览控制，允许点击水面投喂；不会设置系统壁纸。

## 实现入口

- `src/components/DesktopWorldSettings.vue`：现有设置面板中的独立分类。
- `src/shared/types.ts` / `settings.ts`：`worldEnabled`、`worldPaused`；默认关闭，布尔校验；共享脚本生成 Rust 设置契约。
- `src-tauri/src/desktop_world.rs`：平台限制、专用 IPC 来源验证、坐标规则与测试。
- `src-tauri/src/desktop_world/host.rs`：串行宿主生命周期、唯一窗口代次、首帧握手、设置同步、投喂确认、超时及销毁。
- `src-tauri/src/desktop_world/win32.rs`：探测 Explorer 壁纸层、子窗口定位、桌面鼠标采样。支持探测传统顶层 WorkerW 与新 Windows 11 的 Progman 子 WorkerW，实际兼容性仍需实机验证。
- `world.html` / `src/worlds/host.ts`：独立 Vite 入口、渲染桥接、预览、错误与首帧报告。
- `public/worlds/deskworlds`：仅河床和所需依赖；许可证与 `UPSTREAM.md` 随包保留。裸 Three.js 导入改为相对路径，未使用远程 CDN、内联 import map 或放宽 `script-src`。

宿主只向壁纸发送暂停、鼠标位置和投喂命令；`world_event` 只接收初始化、首帧、错误和投喂确认。壁纸使用独立 capability，不能调用通用 `desktop`、更新或账户接口，也不订阅包含消息内容的共享状态。

## 生命周期与失败

开启 → 探测桌面层 → 创建隐藏子窗口 → 初始化回调 → 显示并应用暂停偏好 → 首帧确认 → 运行 / 暂停。
加载超时、WebGL 失败、桌面层不可用会释放自己的窗口，并在设置中保留错误，用户可重载。
每秒检查挂载窗口是否仍有效、主显示器几何是否变化；Explorer 丢失后尝试重建一次，探测失败则提示用户重试，避免无限重启。
关闭后销毁整个 WebView，不保留页面定时器或 GPU 上下文；不修改原系统壁纸文件或注册表，不操作其他壁纸应用的窗口。

当前未实现多屏选择 / 跨屏拼接、遮挡检测、省电模式调度或与其他动态壁纸软件的协调。第一期仍需测量目标 Windows 机器的 GPU、内存和恢复行为，不能从浏览器帧率推断原生功耗。

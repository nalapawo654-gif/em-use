# EM Use v0.4.5

2026-09-14。发布仓库：`nalapawo654-gif/em-use`。本版从包含完整消息交互与物料修订的同一提交创建新标签，沿用现有更新签名密钥。

## 本次更新

- 消息气泡放在桌宠外侧，点击道具或气泡打开独立卡片；玩法期间暂缓气泡，保留道具入口，打开卡片不取消当前短动作。
- 充气牛马使用独立邮包；肥嘟嘟、仓鼠、海狸鼠、小恐龙按当前姿态持物、原杯挂信、膝前摆放或累倒落地，保留手爪遮挡和换装；修仙纸鹤按普通及迷你尺寸避让法器和额度牌；月汐使用月牙信物料。
- 咚咚唤起优先使用当前运行客户端的安装路径，失败显示具体提示；消息账户继续与额度账户独立。
- 纳入角色动作、换装、四档窗口尺寸、消息隐私及卡片交互的浏览器验证脚本和截图。

## 验证与发布边界

本地源码测试、构建及浏览器结果见 [姿态融合记录](design/character-messages-v5/README.md) 与 [消息实现说明](message-notices-implementation.md)。GitHub 标签构建执行版本一致性、素材校验、前端及 Rust 测试，分别生成 Windows x64、macOS ARM64、macOS Intel 安装包和静态服务器整包。

原生安装后消息链路、实际升级及 Windows 交互不因 CI 打包成功而视为已通过。构建链接及实际产物以 `v0.4.5` 对应 Actions 记录为准。手动上传静态整包时保留历史目录，先上传 releases / 页面，最后更新 `em-use/stable/latest.json`。

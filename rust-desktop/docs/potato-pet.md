## 七个机库互动

| 动作 | 入口和反馈 | 完成 / 退出 |
| --- | --- | --- |
| 摸摸头盔 | 主体轻点或玩法入口；机甲手套轻拍，角色晃动与爱心 | 1.8 秒；结束或 Esc |
| 喂口咖啡 | 杯子靠近驾驶舱，角色小憩 | 3.4 秒；结束或 Esc |
| 打开驾驶舱 | 显示驾驶舱小土豆与虚构算式；点击算盘按钮 | 三次间隔至少 240ms 的点击；完成后停留 1.1 秒再恢复；可结束或 Esc |
| 装备锅盖 | 锅盖盾保留在手臂前侧 | 持续，卸下、主体轻点、Esc 或新动作恢复 |
| 插上加油旗 | 红旗挥动与小奖章 | 3.6 秒；结束或 Esc |
| 逗逗战神 | 小碎步摇摆、趣味反馈 | 2.6 秒；结束或 Esc |
| 拧紧螺丝 | 扳手在连接处转动；点击扳手按钮 | 三次独立点击，间隔至少 240ms；完成后停留 1.1 秒；可结束或 Esc |

每次开始替换前一个动作及进度；不累计重复事件。打开衣橱或详情取消动作。失焦 / 隐藏取消短动作与未完成的互动，锅盖装备可保持；切换场景清理计时器和持续姿态。轻柔及系统减少动态模式保留道具、进度和完成条件，停止循环运动。以上互动不改变平台余额或真实业务数据。

- 消息：土豆通信信标，立在右脚旁；新提醒角标和独立消息卡复用共享服务。互动期间保留消息入口、暂缓新气泡，衣橱 / 拖动等遮挡结束后恢复。
- 更新：机甲补给箱，复用更新来信与各平台安装 / 下载规则。
- 道具图集包含终端、信标、补给箱、咖啡、锅盖、旗子、扳手、算盘、手套、爱心、驾驶舱、应急纸箱头盔、齿轮、奖章、推进器光焰与小土豆表情。
- 常规操作仅在悬停、键盘焦点或面板打开时显现；动作反馈始终保留。复用共享拖窗阈值、点击抑制、滚轮 / 四角缩放。衣橱可滚动，迷你尺寸保留关闭入口。
- 接入场景选择、设置、原生托盘、日程场景白名单、消息 / 更新角色映射和原生设置契约。设置契约从共享枚举取合法值，确保新增目录中的 20 款也传入 Rust，避免源码字符串扫描漏值。

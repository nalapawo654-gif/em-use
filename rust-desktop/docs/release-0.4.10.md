# EM Use v0.4.10

2026-09-22。发布仓库：`nalapawo654-gif/em-use`。

## 更新内容

用户可见说明以 [release-notes/0.4.10.md](../release-notes/0.4.10.md) 为唯一来源，打包时写入 `stable/latest.json` 与版本目录 `version.json`。

- 新增 [食人花](piranha-pet.md)，五套皮肤、五种互动及独立日程、消息、更新物料。
- 新增 [土豆战神](potato-pet.md)，20 个皮肤方向、80 个额度形态帧和七种互动；其中 12 套使用对应方向的原创玩具机甲造型，衣橱保留参考名称映射。
- 全部桌宠按形态数量均分额度区间，四态预览为 100 / 75 / 50 / 25，五态为 100 / 80 / 60 / 40 / 20；0% 保持末态。Electron 基线同步额度规则。
- 校验设置契约中的新场景和全部皮肤；同步四个旧桌宠均分预览的已审核迁移哈希，两套代码的对应改动完全一致。

## 验证边界

- 发布前源码验证：171 项业务测试、10 项发布脚本测试、57 项 Rust 测试通过；7 项真实账户测试忽略。版本一致性、更新说明、类型检查、契约生成及生产前端构建通过。
- 迁移与素材：77 个渲染 / 动效 / 手势文件通过对比；56 项 Tauri 素材哈希及 56 项历史图集 RGBA 逐像素校验通过。
- 本轮功能浏览器记录：食人花 100 项、土豆战神 179 项、均分额度 82 项检查通过，记录和截图见各角色文档。
- 原生桌面与真实账户：未进行本版安装器、原生窗口、真实日程 / 消息 / 账户验收；编译与模拟浏览器检查不替代这些验收。
- 标签工作流生成 Windows x64、macOS ARM、macOS Intel 安装包及静态服务器整包，最终结果以对应标签的 GitHub Actions 为准。

Mac 保留手动下载 DMG 替换；Windows 保留签名自动更新。静态服务器仍须手动上传：保留旧版本，先上传本版目录和页面，最后更新 `em-use/stable/latest.json`。

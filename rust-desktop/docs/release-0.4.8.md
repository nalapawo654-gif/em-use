# EM Use v0.4.8

2026-09-16。发布仓库：`nalapawo654-gif/em-use`。

## 本次更新

- Mac 仅主动检查版本，通过固定下载页获取对应芯片的 DMG；关闭后台检查、应用内安装与自动重启。Windows 保留现有检查、签名验证、安装重启流程及签名密钥。
- Mac 安装包使用完整应用的 ad-hoc 签名，CI 校验应用目录和 DMG 内应用的资源签名。未配置 Developer ID 或 Apple 公证，首次启动仍可能需要在系统隐私与安全性设置中允许。
- 同一会话连续来信复用气泡，原地更新最新内容和条数。气泡关闭或超时后，同一会话持续来信只更新角标，安静满 30 秒后再来消息才重新提示；全部查看或消息账户切换后重置，不将消息误标为已读。
- 静态站点同时提供 Windows 安装器和两个 Mac DMG；更新清单仅为 Windows 提供更新包，Mac 主动检查读取顶层版本信息。旧 Mac 客户端需通过下载页手动升级。

## 验证与发布边界

本地功能验证：157 项 TypeScript 测试、8 项发布脚本测试、35 项 Rust 测试通过；3 项真实账户测试按原配置忽略。类型、前端构建与素材 / 交互基线检查通过。浏览器验证 Mac 手动更新入口、Windows 安装调用、同一气泡连续 4 条消息合并、关闭 / 超时后的静默及不同会话提醒。新增打包校验能拦截原 v0.4.7 缺少签名资源封印的 Mac 应用。

本次只确认 `v0.4.8` GitHub Actions 发布工作流启动，不持续跟踪构建完成。新 DMG 的实际安装启动、Windows 原生更新和真实咚咚来信仍需目标机器验证。构建产物及静态服务器包以该标签工作流的最终结果为准。

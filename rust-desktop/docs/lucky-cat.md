# 破产招财猫

公共窗口、账户、设置与验收遵循 [桌宠基础交互规范](../../docs/desktop-pet-interaction-standard.md)。实现位于 Tauri 项目，保留已有角色。

## 角色与额度

以用户提供的 `招财猫.png` 为外观参考：三花绒毛、金链、墨镜、元宝和打工道具。透明桌面只保留猫、当前道具、台词及实时额度；浏览器采用奶油金与朱红色的展示页。

额度 >60% 为戴墨镜的富足姿态；>20% 为笔记本前工作；>15% 为抱住最后一枚硬币；≤15% 为破碗求助。未知采用中性工作姿态，数字为 `—`，台词等待同步。过期、跨日、无权限等由共享状态提供；互动不修改额度。

## 专属互动

| 动作 | 入口与手势 | 反馈与完成 |
| --- | --- | --- |
| 招招财 | 主体点击、悬停工具、玩法面板 | 举爪抱元宝，金币跃起；3.2 秒结束 |
| 喂条小鱼 | 工具或面板点击 | 抱住红鱼点心，爱心上浮；3.6 秒结束 |
| 续杯咖啡 | 工具或面板点击 | 戴墨镜喝咖啡、杯口热气；4 秒结束 |
| 认真赶工 | 面板点击 | 笔记本工作姿态、敲字反馈；4.2 秒结束 |
| 纸箱摸鱼 | 面板点击 | 趴入纸箱、呼吸与睡眠提示；持续到点击主体、回来或 Esc |
| 送个红包 | 面板点击 | 红包与举爪开心反馈；3.2 秒结束 |

以上均为点击动作，不声称需要拖动或计算覆盖进度。一个主要动作替换前一个；再次选择从头开始。自动动作结束后恢复真实额度姿态，持续摸鱼有可见恢复入口。Esc 在容器级关闭面板并取消动作。失焦、页面隐藏及卸载清理动作计时。

配饰独立保存：原味金运、红绳福牌、青玉平安。昼夜使用相同角色素材和不同界面光色，保持三花与道具原色。轻柔模式停止装饰粒子、抖动和持续姿态变换。

## 素材来源

内置 imagegen 生成，参考根目录 `招财猫.png`。最终素材为 `public/assets/luckycat/atlas.png`，4×2 格，按富足、工作、抱币、空碗、招财、喂鱼、咖啡、纸箱排列。运行时缓存解码、绿幕去色，逐格保留完整轮廓；不把整张参考图作为界面。

提示词要点：保持绒毛三花招财猫、金链与圆脸；生成八个完整独立姿态，均匀 4×2 布局，每格留边，无文字、气泡和场景背景。首次透明请求输出了不透明棋盘格，因此再次通过内置 imagegen 替换为纯绿色背景、缩小每格主体并保留八个造型。绿色只用于运行时遮罩。

## 2026-09-12 动画与服装升级方案

用户要求真实的日常动作过程和明显不同的服装。新增四套独立绘制素材：原味金链、财神唐装（红金帽 / 上衣 / 长袖）、咖啡师（贝雷帽 / 衬衫 / 蓝围裙）、星星睡衣（睡帽 / 绸缎睡衣）。保留原设置键；`festival` 升级为唐装，`jade` 升级为咖啡师，新增 `pajamas`。每套都有满 / 中 / 低 / 空四档完整造型，以及头部三表情、无头无前臂躯干、两条独立前臂、咖啡杯、元宝，共 12 个独立部件。

动作采用部件关节动画：招财抬爪并来回摆动；眨眼闭合 / 睁开两次；伸懒腰拉伸躯干、抬高双臂并张嘴哈欠；咖啡从低处举到嘴边、倾杯、闭眼再放下；抛接元宝包含抬爪、离手、空中抛物线、旋转和落回肉垫。补充蹭脸、歪头和打盹。喂鱼、敲键盘、纸箱、红包也保持当前服装并由分层道具呈现。

日常动作间隔 5–12 秒，首个动作约 1.8–3 秒后开始；避免连续重复。满额度提供全部日常动作，中额度偏向咖啡 / 开工 / 伸懒腰，低额以安静动作陪伴，空额度仅眨眼 / 打盹 / 歪头，未知不自动展示消费或庆祝。打开面板、拖窗、后台隐藏、轻柔模式暂停日常动作。全部动作继续支持主动选择和容器级 Esc，定时器、RAF、媒体监听在卸载时清理。每次画布清空后只绘制一套身体部件，不叠两只完整猫。

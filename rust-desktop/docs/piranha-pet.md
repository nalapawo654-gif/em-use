# 食人花 · 捕需求草

2026-09-22。接入当前 `rust-desktop` Tauri 客户端；公共操作遵循 [桌宠基础交互规范](../../docs/desktop-pet-interaction-standard.md)。参考图作为角色美术参考，不把图中文字当作功能指令。

## 角色与额度

奶油陶盆、桃色花瓣、厚绿叶和圆牙齿。透明桌面无底板；盆前小木牌独立显示真实额度。>75% 花稳稳满，>50% 张嘴等需求，>25% 垂叶疲惫，≤25% 合苞休息（按公共规范，仍有余额不称耗尽）；0% 同为合苞姿态；未知为中性外观与 `—`。过期、跨日、不可用、未登录各自显示共享状态。动作完成后重新取当前额度姿态。

经典、樱花、仙人掌、万圣节、圣诞五款，后三类造型独立绘制，所有换装均保留四档额度姿态。昼夜使用共享主题，夜晚轻微压暗素材；轻柔及系统减少动态效果停止持续摇摆。

## 专属互动

| 动作 | 入口与手势 | 道具与反馈 | 完成 / 取消 / 重入 |
| --- | --- | --- | --- |
| 投喂需求 | 常用工具、玩法面板，点击 | 虚构需求纸条滑入嘴边，张嘴后咀嚼；不读取或删除真实需求 | 3.2 秒完成；结束或 Esc 取消；重复点击从头播放 |
| 夸夸开花 | 常用工具、玩法面板，点击 | 花冠舒展、桃色小花浮起 | 2.4 秒完成；结束或 Esc 取消 |
| 逗逗花 | 玩法面板，点击 | “这个很简单”纸条与生气摇头 | 2.6 秒完成；结束或 Esc 取消 |
| 摸摸花冠 | 主体轻点、常用工具、玩法面板 | 笑脸轻晃和小花反馈 | 1.8 秒完成；拖动后的点击由共享手势抑制 |
| 合苞小憩 | 玩法面板，点击 | 合苞 / 闭眼持续休眠 | 起床、主体轻点、Esc 或其他动作恢复 |

一次一个动作，新动作替换旧动作；面板互斥，打开面板结束当前动作。窗口失焦及页面隐藏取消短动作，组件卸载清理计时与监听。不需要双击、拖擦、进度条或自动执行。互动、换装及休眠不改变真实额度。

## 日程与消息物料

- 叶片翻页历：盆左侧独立叶茎底座，奶油空白纸页上由界面叠加真实时间。复用 PetCalendar 与原生日程调度、账户切换和去重。
- 藤蔓来信：盆右侧落地藤蔓托住奶油信封，桃花封蜡；来信仅在未查看提醒大于零时出现。主体动作与换装不会移除消息入口，互动期间暂缓新消息气泡。
- 花种补给：更新入口使用独立的种子袋图形和文案，复用原更新服务。
- 日程、消息、更新面板互斥；衣橱、玩法、拖窗时道具让位。三个物料落点避开主体热区、额度牌、工具与缩放柄。

## 共享交互

- 启动后独立于登录检查版本，之后定期检查；内网不可达时后台重试。自动检查不弹错误对话框。
- 发现新版后，桌宠上方出现明确标注「新版本」的来信入口，短暂入场后静止，不抢焦点、不强行显示被收起的桌宠。
- 面板、当前互动或拖动进行时，来信让位。角色恢复空闲后显示，不抢占玩法道具。
- 点击来信展开非模态卡片，显示目标版本、说明、「更新并重启」和「稍后」。明确安装会重启。点击前绝不下载或安装。
- 展开状态禁用角色操作和缩放；Esc、关闭或「稍后」收起，按版本共享记录到本机。换角色、重启不会对同一版本反复提醒；悬停时仍能找到收起的入口，托盘保留新版本标识。更高版本重新提醒。
- 下载显示确定进度或不定进度；失败保留错误与重新检查入口。最新状态由原生层广播给设置页和全部角色，不以本地动画冒充安装成功。
- 小尺寸优先保持操作按钮可达，220px 及以下通过「说明 ↗」打开设置页的版本更新；较大窗口的长说明独立滚动。夜间沿用对应角色配色；轻柔模式和系统减少动态效果设置关闭来信动效。
- 所有入口支持键盘、焦点可见，更新提示不改变额度值、额度状态或登录状态。鼠标穿透 / 收起时可从托盘进入版本更新。

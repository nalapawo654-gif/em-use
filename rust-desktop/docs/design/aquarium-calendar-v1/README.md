# 小鱼缸 · 缸沿挂历

用户授权继续给小鱼缸接入日程。沿用同一日程和提醒能力，按原水景独立设计物料，不更换鱼缸皮肤或原玩法。

## 设计

冰蓝珐琅、奶油色防水纸面、黄铜双环和一枚贝壳浮雕；弯钩搭在左上缸沿，纸牌留在玻璃外侧。原水泡来信在右侧保留，避免把消息与日程画成两个相同水泡。标题、地点和操作出现在外侧独立窗口，纸牌仅提示下一项时间。

原图 1536×1024，通过共享去绿底函数保留原像素轮廓。生成参考为原缸体；精确提示词、文件位置与生产说明见 [素材记录](asset-production.md)。

位置按窗口比例固定：点击区 x=0–18%、y=0–15.5%；整个装饰画幅 x=0–25%、y=0–16.67%。主纸牌实际落在左上，右侧只有细挂钩接触缸沿，装饰区域不拦截点击。最小 180px 时入口约 32×28px，时间详情在正常字号的卡片阅读。迷你隐藏悬停文案，保留可访问名称及键盘点击。

不随水位、鱼装扮或游动变形；提醒仅纸面一次 1.2 秒淡闪，挂钩不摇。擦玻璃、躲猫猫、宝箱和喂食继续原状态。覆盖面板/拖窗优先，暂藏日历；当前玩法只暂停纸面提示动效。

## 接入

共用 `PetCalendar`、`CalendarCard`、原生日程调度、独立日程窗及原有手势。设置从“牛马帮你记着”改成“伙伴帮你记着”，明确两种入口。牛马的 DOM 类名、道具位置和外观保留。未改 Aquarium.vue、鱼缸画布、游动算法、水位映射、原道具、公共窗口手势。

## 验证与复现

运行 `npm run dev -- --port 5189` 后打开 `/tests/fixtures/desktop.html?scene=aquarium&width=440&calendar=1&messages=1&motion=off&qa=aquarium-calendar`。

开发工具运行实际 Vue 组件，使用演示桥接。布局矩阵：4 尺寸 × 4 装扮 × 2 昼夜 × 6 水位（包括未知）× 6 玩法 = 1152。操作栏强制展开，检查日历与鱼、宝箱、洞穴、额度、提示、原操作和缩放柄的碰撞及命中；详细结果保存在 [layout-result.json](qa/layout-result.json)。

原生桌面窗口、真实到点弹窗、系统通知及多屏尚未实测；浏览器模拟原生窗口不作为这些层面的通过。没有打包、提交、推送或发布。

## 2. 角色与视觉

一句话：一只爱搬家、又特别护家的小螃蟹。情绪顺序是好奇、认真、笨拙、得意；不做凶狠战斗角色。

- 身份锚点：橘红色软胶身体、两根圆润眼柄、不对称大小钳、短腿、偏害羞的表情。所有皮肤和觉醒形态保持同一角色。
- 材质：有轻微磨损的牛皮纸、哑光青绿金属、奶油色纸板。正文色参考 #50382B，身体 #E98654，青绿 #69B8B6，纸板 #C79C6C，觉醒局部薄荷光 #9EDDD0。
- 小尺寸简化纸纤维、铆钉和缝线；优先保留眼神、钳子、房屋轮廓。用轮廓和姿态表达状态，不能只靠颜色。
- 不画大平台、完整风景或常驻发光底座。常态只保留小家、宠物、一个门前摆件及额度牌。
- 最大城堡含旗帜的轮廓须与其他两套共用可比较的占位和地面基线，不能为了塞进城堡把螃蟹缩成看不清的小点。

觉醒时保留所选配饰身份：叶片帽折叠成不遮眼的小叶饰，工牌换薄金属夹，邮包换同色布包；帽、护目镜、纸冠共用排斥区域，整身素材要画出兼容造型，不能直接叠三层头饰。摆件仅调整包边材质，不增加持续光效。

卷尺、胶带、羽毛是玩法道具，只有对应动作运行时出现。选择保存不受换来源或变身影响。

## 5. 日常动作调度

| 动作 | 拟定时长 / 频率 | 表现 |
| --- | --- | --- |
| 呼吸、眨眼 | 呼吸 4–6 秒一轮；眨眼不规则约 4–9 秒 | 身体轻起伏，眼柄不持续大幅摆动 |
| 探头张望 | 2–3 秒，偶发 | 看左、看右，再回正；无全局鼠标跟踪 |
| 整理小窝 | 2–3 秒，偶发 | 三皮肤分别补胶带、扶拉环、扶旗 |
| 晒钳伸懒腰 | 约 2.4 秒，偶发 | 抬钳、眯眼、回到当前额度姿态 |
| 扶正门牌 | 约 1.3 秒 | 仅选中门牌时进入随机池 |
| 困困打盹 | 约 4 秒短动作 | 眼睛半闭，头靠门沿；与用户主动宅家状态区分 |

随机小动作每 25–45 秒最多挑一个，不连续重复同一动作。低额度减少动作频次和幅度；零额度不随机巡逻。打开面板、拖窗、用户玩法、变身、窗口隐藏时暂停随机动作。重新显示不补播积压动作。全局轻柔模式只保留静态姿态和少量眨眼，关闭动效则静态切换。夜间用较暖较暗的同材质表现，不以夜晚推断额度或强制休息。

## 6. 四个主要玩法

统一：同一时刻一个主要玩法。每次结束、取消、被新玩法替换、切换桌宠都清掉临时道具、捕获、延迟回调；新动作从自身初始状态开始。Esc、当前动作提示中的结束按钮都可退出。短动作结束回当时额度姿态，不能强制回精神饱满姿态。未设计双击功能。

| 名称 / 入口 | 手势和有效区域 | 道具与反馈 | 完成 / 取消 / 重入 |
| --- | --- | --- | --- |
| 敲敲门：主体轻点、快捷入口 | 按下释放位移小于公共 5 px 阈值，作用于住处主体；按钮与配饰独立处理 | 门盖轻响动，眼柄先探出，再挥小钳；默认无声音 | 约 1.5 秒自动结束；运行中再次点击不叠加，最多重播一轮；Esc/结束立即收束 |
| 看新房：衣橱卡片“试住”、更多玩法 | 衣橱内点候选住处，播放预览；“住这里”才提交选择 | 小卷尺、试探钻入、回头展示；始终只有一只蟹，旧家和新家最多短时并存 | 试住动画约 3 秒后保持候选预览；“住这里”保存并关闭面板，关闭/Esc恢复已选住处；连续预览取消旧动画，只保留最新候选；无自动保存 |
| 逗钳子：快捷入口、更多玩法 | 开始后在主体附近的羽毛活动区移动指针，按住拖动羽毛；进入指定抓取圈并释放为一次有效抓取；键盘方向键移动、空格抓取，也提供“递给它”按钮 | 羽毛跟指针，眼柄先跟随，小钳扑一下；前两次轻碰，第三次抓住举起；显示 0/3、1/3、2/3 | 三次独立有效释放/按钮操作后约 1 秒庆祝并结束；同一按住过程只计一次，区域外释放不计；Esc/结束取消；重新进入从 0 开始 |
| 宅家休息：快捷入口、更多玩法 | 点击启动；“叫它出来”恢复 | 收拢门前摆件、闭眼缩回、门口小牌；眼睛或钳尖仍可见 | 持续状态不自动结束；保留恢复按钮且不随 hover 隐藏；Esc恢复；再次选择等同唤醒 |

“看新房”使用衣橱内动画舞台，窗口主体在提交前保持当前已选外观；避免候选预览触发生产觉醒状态机。觉醒来源下预览相应觉醒服装，提交并关面板后才按共享机制播放换装。

逗钳子开始后仅有效玩法区域占用拖动，必须接公共手势排除规则。正常主体拖动继续移动窗口，沿用拖动后 400 ms 点击抑制。羽毛不得靠近额度牌或结束按钮造成遮挡。进度只用于此玩法，其他动作不增加进度条。无自动完成按钮；“递给它”是等价的单次有效操作。

配饰轻点属于短反馈动作。主要玩法运行时不触发配饰反馈；配饰反馈运行时新主要玩法可以打断。

## 7. 额度与状态

读取共享额度状态，不新增账户、登录或查询逻辑。Codex 每个实际返回窗口独立显示名称、剩余百分比和详情；只返回周窗口时只画一行，不补造 5 小时窗口。AI 云平台保持其真实来源单位，不转换为虚构 Token 或请求数。

| 状态 | 日常造型 | 已觉醒造型 |
| --- | --- | --- |
| 高额度 | 身体探出、眼神好奇、房屋开口舒展 | 穿完整服装，局部弱光，可做普通日常动作 |
| 中额度 | 一钳靠门，站姿放松 | 完整服装，减少装饰光与抬钳幅度 |
| 低额度 | 头靠门沿、半闭眼、动作变慢 | 工程师伏图板、航行员半入舱、守护者裹披肩 |
| 零额度 | 缩回小家，挂“今天不搬了” | 保留服装与升级住处，熄装饰光，不退回旧造型 |
| 未知 | 额度牌显示 —，蟹拿空白账单挠头 | 无有效额度不新触发觉醒；不画满能量灯 |
| 同账户数据过期 | 数值按共享过期语义标注 | 可保留已确认造型，关闭额度光效，显示更新状态 |
| 断开 / 身份失效 | 恢复普通外观并显示真实连接状态 | 不继续保持已失效账户的觉醒表现 |

视觉分档阈值沿用现有共享映射，本文不新增另一套百分比阈值。多窗口以有效窗口中剩余比例较低者驱动角色。用户宅家是独立意图：额度更新不强制唤醒，唤醒后才回到当时额度姿态。所有玩法不修改额度。

| 皮肤 | 完整服装与住处变化 | 保留身份 | 日常 / 互动适配 |
| --- | --- | --- | --- |
| 折纸工程师 | 纸板折叠工坊、制图板、奶油工作背心、折纸护钳；折痕薄荷光 | 胶带、手绘小窗、纸纤维 | 胶带动作改为压牢工坊折痕；原来的卷尺量房、护家、抓羽毛入口与完成条件不变 |

## 9. 变身分镜

沿用 1.6 秒四段。效果集中于身体和小家，数值牌、面板、通知均不闪白、不位移，特效不接收指针。

| 时间 | 折纸工程师 | 汽泡航行员 | 星堡守护者 |
| --- | --- | --- | --- |
| 0–0.3 秒 蓄能 | 缩身合钳，胶带接缝亮起 | 藏到罐口下方，拉环抬起 | 合钳低头，旗帜折下 |
| 0.3–0.8 秒 成形 | 箱盖按折痕展开工坊，背心与护钳逐段折成 | 罐沿旋转、侧舱展开、领口合拢，护目镜落位 | 短塔展开、披肩扣上、纸冠在两眼间立起 |
| 0.8–1.3 秒 亮相 | 举大钳，另一钳稳住制图板 | 抬头小钳敬礼，冒两颗气泡 | 托起护钳，旗子舒展，少量纸星散开 |
| 1.3–1.6 秒 收束 | 折痕光回落，回当前额度姿态 | 侧舱光回落，保持落地 | 纸星消散，星灯收暗，回当前额度姿态 |

从低额度开始变身时，亮相短暂且克制，收束必须回低额度；不得把亮相画面留作满额姿态。零额度同理。

- 切回普通来源约 0.6 秒：按各皮肤结构反向收回新装备，保留已选配饰和摆件；不是整张立绘交叉淡入。
- 觉醒状态换皮肤沿用完整 1.6 秒，新住处和服装素材就绪后开始；普通状态换皮肤约 0.8 秒。
- 轻柔模式约 0.2 秒，减少展开幅度和粒子；关闭动效直接呈现目标造型。两者均不丢失来源对应的衣服。
- 启动恢复、额度刷新、后台重连不重复播放仪式。面板、消息、日程、拖动、互动占用时排队，连续变更只保留最新目标。
- 宅家属于持续主要玩法：切来源先保存目标，待唤醒或结束后执行变身，不通过变身强制唤醒。
- 播放中发生拖动、面板占用、隐藏或切宠，服从共享控制器的取消/收束决定，清空局部特效与计时器。
- 素材失败保留可读旧外观和明确重试提示，不改变来源、额度或选择；回退与新服装未就绪要有可区分的状态。

## 10. 桌面布局、消息与面板

拟定 440 px 设计坐标：宠物与住处主体约位于 x=58–340、y=70–340，脚部基线约 y=334；额度牌位于下方中央，门前摆件放左下。右上和右侧留给公共弧形操作带，实际以共享几何及碰撞检查校准，不创建第二套工具栏。

- 未悬停：只显示主体、配饰、摆件、核心额度。额度牌显示真实窗口名称和数值，图稿不烘焙数字。
- 悬停：上弧为更多玩法、衣橱、设置、收起；右弧为敲敲门、逗钳子、宅家。看新房从衣橱和更多玩法进入。
- 打开面板：衣橱、玩法、额度详情互斥，关闭和容器级 Esc 可用；鼠标离开仍可操作。面板优先于工具和缩放手柄。
- 300 px：缩短非必要台词，不挤掉额度窗口标签。190 px：按公共规则仅保留管理入口，玩法从更多进入；不绘制过密配件纹理。
- 消息：一封信夹门边，小钳指向它；复用现有通知面板。信封独立锚点不盖眼睛或额度；不把信件视为新养成物品。
- 日程：门边一张可读提示便签，到点轻敲门牌；使用已有日程服务，不擅自创建日程。
- 更新：门侧迷你补给包，使用现有更新入口与真实版本信息。
- 夜间：额度牌独立保证对比度，收暗材质，移除高频闪光。系统减少动态效果优先。

## 11. 后续素材交付与实施边界

本轮仅交付设计稿。后续生产素材应从此角色稿重新生成 / 绘制独立透明帧，不能把整张带字设计稿直接切块接入。

拟定素材包：

1. 三套普通皮肤与三套觉醒皮肤，每套高、中、低、零、未知、主动休息六个基础姿态；过期以共享状态叠加呈现。
2. 眨眼、探头、整理、伸懒腰的可插值关键姿态；每皮肤单独校准眼柄、钳子、开口及衣服关节。
3. 四主要玩法的起始、接触、反馈、结束关键姿态；服装不脱落、不产生多余手脚。
4. 每套变身至少六个生产关键帧（蓄能、初成形、成形、展开、亮相、收束），本稿四列是叙事分段，不等于最终帧数。

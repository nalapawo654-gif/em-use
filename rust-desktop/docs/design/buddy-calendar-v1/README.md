## 必须保留的原物料及交互

- 正式实现沿用原始牛马骨骼、五套皮肤、四档额度、草地与木牌，生成稿中的角色是参考重绘，不可替换正式角色图。
- 原消息邮包保持右后脚落点和点击入口；现有六项照顾工具、设置、收起、更多玩法、衣橱、额度详情及四角缩放均保留。
- 单击摸摸、双击站趴、5px 拖窗阈值、拖动后点击抑制、清洁指针手势继续共用原逻辑。日程按钮应在公共手势捕获阶段被明确排除，不能只在冒泡阶段阻止事件。
- 提醒不调用主要玩法的 act，不取消充气、刷洗、喂草、休息等当前动作，不改变额度映射。
- 提醒动效仅在新增物料的局部层运行；木牌、额度数字和身体不参与摇摆。
- 使用独立外侧提醒窗口与日程卡，沿用消息窗口边缘避让及焦点处理经验，但待实测；卡片互斥，不能抢占正在阅读的卡片。
- 概念中的会议信息均为 2026-09-15 演示内容，不是当日日程查询结果。

## 原画细化与落地拆分

选定方向后再导出独立透明物料：固定底座/夹具、活动表面/纸页、提醒标记；接触阴影需独立控制。数字、标题、按钮和角标由界面渲染，不烘焙进物料。选定前这三张均是整页概念稿，不是已拆分的运行贴图。

材质应复用现有暖木色、黄铜、奶油色与蓝色；接触点应有真实夹持或地面支撑。日程物料独立于角色身体缩放和压扁。正式角色整体缩放时道具同步布局，不随额度变形。

## 视觉检查及待修正

- 三张已目视检查：均保留左侧额度木牌、右侧消息邮包；会前提示标题、时间、地点和三个操作可辨。真实运行尺寸未验证。
- 三张生成稿的角色与原素材存在比例/表情细微差异；仅用于新增物料和整体关系评审，禁止替换原角色。
- 报时钟：钟面指针在稿中是装饰，正式方案应明确是否报真实当前时间；推荐静态时钟图标配合界面时间，避免错误指针误导。
- 预约票：翻面微交互应是视觉反馈，不得把“查看日程”偷换为忽略提醒。正式材料移除烘焙的 15:00，重叠界面文字。
- 翻页历：生成稿主视图偏向立柱右前侧，可能与充气泵、趴下头部占位冲突。若选此稿，必须改至立柱左侧并用真实动作验证，当前不能声称无碰撞。
- 生成稿中的小字和金额并非程序渲染，缩略图细字不作为数值准确性验收。

## 下一阶段验收边界

尚未进行浏览器、原生桌面、真实日程调度验证。选定后需要覆盖 440/300/190/180px、五套皮肤、四档额度、未知态、站/趴/充气/清洁/喂草/玩球、日夜及轻柔模式。特别检查左侧物料与木牌、充气泵、水桶、草料、头部和缩放柄的重叠。

窗口层需要验证：拖窗不误开日程；开日程不触发摸摸/刷洗；现有动作不中断；消息卡与日程卡互斥；新提醒不抢键盘焦点；关闭/失焦行为；穿透与收起的替代入口。

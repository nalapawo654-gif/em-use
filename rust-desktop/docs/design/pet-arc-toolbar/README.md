# 全角色环抱操作带

2026-10-16。用户已选定肥嘟嘟效果稿，并要求所有桌宠采用同一形式后直接实现。
视觉基准：[已选效果稿](approved-feidudu.png)。公共行为遵循[桌宠基础交互规范](../../../../docs/desktop-pet-interaction-standard.md)。

## 结构与尺寸

- 右上到右下的单条弧带：上段为更多玩法、衣橱、角色额外管理入口、设置、收起；下段最多四个角色常用互动。文字保持水平，原有道具或 Phosphor 图标沿用。
- 左上仅保留轻量名称；台词、额度、消息和日历各保留原职责。主体不铺大底板，原生透明背景不变。
- 标准 440 px：图标加动作名。紧凑 300 px：管理和互动使用图标，悬停显示原动作名称，避免沿弧线挤压文字。小于 280 px：隐藏快捷互动并扩大管理扇区；全部动作可从更多玩法进入，名称由 aria-label/title 提供。
- 180–800 px 下弧带都在窗口内部；弧面为真实按钮命中区，中心留空，不占用拖窗区域。面板、动作提示、日历和通知遵守原有互斥、显隐和缩放让位规则。
- 未悬停隐藏；容器 hover、键盘可见焦点、面板打开时显示；打开独立日历、通知或截图时让位。动作结束按钮独立保留。深色与轻柔模式适配。

## 13 只桌宠的设计

| 桌宠 | 弧带材质与点缀 | 形体适配与入口 |
| --- | --- | --- |
| 额度小鱼缸 | 冰蓝瓷白、湖蓝线条 | 弧线让出缸口；衣橱并入上段；下段喂鱼、清洁、宝箱、躲猫猫 |
| 充气牛马 | 雾蓝奶白、蓝灰线条 | 保留草地、木牌；常用喂草、喝水、摸摸、清洁，其余归更多玩法 |
| 林间海狸鼠 | 亚麻浅绿、橄榄点缀 | 梳毛、喂面、喝水、拍照；送木头仍在更多玩法 |
| 仓鼠动力机房 | 奶油燕麦、焦糖线条 | 让出跑轮；喂瓜子、梳毛、铃铛、逗猫；咖啡、盖被子保留在玩法 |
| 修仙渡劫事务所 | 玉白青绿、竹青线条 | 管理段保留仙境；仙人原有前四项互动，其余在玩法 |
| 健身电池人 | 薄荷瓷白、深绿点缀 | 举铁、充电、太极、健美操；瑜伽、休息及其他运动均在玩法 |
| 肥嘟嘟 | 奶油象牙、焦糖线条 | 对齐已选设计；奶茶、饼干、肚子、加班 |
| 水墨小狐 | 米白纸感、墨灰朱砂 | 保留原三项专属互动与墨色入口 |
| 破产招财猫 | 米白浅金、苔绿与朱红 | 保留原三项专属互动与衣橱 |
| 小恐龙 | 香草浅绿、青苔描边 | 保留原专属四项互动与换装 |
| 月汐 | 珍珠冷白、雾蓝紫 | 管理段保留武器库；保留原三项互动 |
| 食人花 · 捕需求草 | 嫩叶浅绿、苔绿线条 | 让出花冠；投喂需求、夸夸开花、摸花冠 |
| 土豆战神 | 暖灰金属、橄榄线条 | 让出头盔装备；咖啡、加油、摸头盔 |

共用呈现组件，不复制账户、额度、设置或窗口手势服务。角色动画、动作名称、完成条件、素材与额度状态机沿用。验收另记录源码与测试、浏览器、原生和真实账户四个层面。

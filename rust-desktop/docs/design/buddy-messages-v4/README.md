# 充气牛马 · 身侧邮包修订

2026-09-14。只调整充气牛马；以下均为当前组件渲染截图，消息和额度为浏览器演示数据。

![实际状态对照](overview.png)

## 位置与物料

- 蓝色皮革邮包、金色搭扣、露出的奶油色信封，按用户提供的牛马参考图重新生成。固定放在右后脚旁的草地上，独立于角色骨骼；不跟着身体压扁、抖动或换皮肤变形。
- 点击框左上角为场景的 `73%, 65%`，宽高均为 `24%`；图内邮包底部约在场景高度的 `87%`。440 / 300 / 190 / 180 px 均实测。角标位于信封右上方。
- 原有六项照顾入口保留，改为右上方两列三行，给地面邮包留出位置。没有消息时仍使用原工具栏布局。
- 新来信时邮包以底部为支点轻摆一次（0.8 秒、最大 3°），随后静止。轻柔模式及系统减少动态效果时不摆动；不循环闪烁。

## 状态与交互

| 状态 | 邮包 / 消息行为 |
| --- | --- |
| 待机、四档额度、站立 / 趴下、五套皮肤 | 同一个落地点，保留入口与角标 |
| 喂草、喝水、摸摸、清洁、玩耍、驱蚊、摇尾、打盹、抖动、趴下休息、充气、庆祝 | 邮包可点；只暂缓气泡，动作结束后提示待提醒消息 |
| 清洁中点邮包 | 打开独立消息卡，不触发刷洗、摸头或拖窗；原动作保持 |
| 衣橱 / 更多动作 / 额度详情、拖窗、更新卡片 | 覆盖面板期间暂藏入口，关闭后恢复；不清除消息 |
| 点击邮包 / 气泡 | 在桌宠外侧打开消息卡，卡片内“打开咚咚”沿用客户端唤起服务 |
| 收起气泡 / 卡片 | 保留邮包；仅实际看见的消息减少本工具角标，不写回咚咚已读 |
| 暂停 / 隐私 | 暂停显示静音标记；隐私模式不展示姓名正文 |
| 退出额度账户 / 咚咚换号 | 前者保留消息；后者清除旧来源入口、气泡、角标 |

## 验证证据

- `scripts/buddy-message-qa.cjs`：5 皮肤 × 4 额度 × 13 动作（含待机）× 静态 / 动态 = **520 个组合**，检查起势、执行、恢复及回待机，共 **1,920 个状态采样**。邮包位置保持不变，入口持续可见。
- `scripts/buddy-message-layout-qa.cjs`：5 皮肤 × 4 额度 × 4 尺寸 × 昼夜 = **160 组**；邮包不遮挡额度、台词、按钮、缩放柄，点击中心可达。
- `scripts/buddy-message-flow-qa.cjs`：实际点击清洁 → 邮包 → 消息卡 → 打开咚咚桥接；自动清洁 → 庆祝 → 待机补弹；双击趴下 / 恢复；衣橱全部五套换装；喂草中静态 / 动态切换；额度退出、暂停、隐私、咚咚换号。
- 共享消息回归：悬停计时、收起不清数、会话合并、实际显示才确认、阅读中接收新消息、更新互斥、其他桌宠玩法暂缓。
- 源码检查：149 个 TypeScript 测试 + 5 个脚本测试、类型检查、构建及旧角色素材 / 动画一致性校验。原牛马骨骼、动画参数、皮肤贴图、额度算法未修改。
- **边界：**上述为浏览器实际组件与模拟窗口 / IPC，不代表 Windows / macOS 原生桌面全流程通过。本轮未重新验证真实咚咚收消息或客户端唤起，也未发布新版安装包。

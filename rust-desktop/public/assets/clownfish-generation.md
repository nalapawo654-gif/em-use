# Clownfish artwork

Generated using the built-in image_gen tool from the original project design board; selected output 1254×1254, RGB on a white studio background. Two earlier independent new-fish requests failed tool output moderation; the successful request extracted the reference icon instead.

Exact successful prompt:

Extract the small orange and white aquarium fish icon from the bottom 'icons and materials' row of this supplied design board, the first fish icon just right of the color palette. Produce just this one fish isolated centered large on a pure white background, keep its exact cute glossy 3D design and right-facing orientation. Remove all typography, UI, aquarium and other objects. This is a simple UI asset extraction for the supplied desktop aquarium design. One fish only, not a design board. 1024 square. White background.

The renderer masks the border-connected white background at runtime, preserving the source image and the fish's enclosed white stripes.

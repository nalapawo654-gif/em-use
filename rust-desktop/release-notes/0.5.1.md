桌面世界与全新启动片头上线。

• Windows 新增独立「桌面世界」模式，首个河床场景支持主屏桌面壁纸、鼠标互动、投喂和暂停，可通过现有设置与托盘控制，默认关闭。
• 新增约 3 秒的 EM Use 启动片头，支持点击跳过或按 Esc 跳过；可在「设置 → 桌面偏好 → 启动片头」关闭。
• 开机自启动及减少动态效果时跳过片头；片头结束后释放播放资源，并为异常加载提供超时兜底。
• 调整安装包平台：保留 Windows x64 和 Apple Silicon Mac，不再提供 Intel Mac 安装包。

河床场景使用 GPU 渲染，集成显卡上的占用可能较高，可在不需要时暂停或关闭桌面世界。
更新方式：Windows 保留签名自动更新；Mac 手动检查并下载 DMG 替换。

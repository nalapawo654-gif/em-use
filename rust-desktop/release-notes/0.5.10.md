# EM Use 0.5.10

- 新增「额度变装小人」：Claude、GPT、Gemini、豆包四种趣味形象随当前额度切换，支持打招呼、整理行头、抽状态签和 Codex 觉醒服装。角色名称不代表实际切换模型，互动不改变真实额度。
- 新增「项目协作」独立窗口：管理项目背景、消息、Agent、任务与成果，支持人工验收和单次执行许可。设置和托盘均可打开。
- 新增 Agent 接入向导与随包 MCP，可生成 Codex、DeepSeek Harness、AiWork 等宿主的配置。需要自行部署协作服务并按宿主要求手动加载配置；不会自动唤醒或接管宿主。
- 保留投篮小鸡、纸箱寄居蟹和已有桌宠，下载页更新为 16 个伙伴。

macOS 仍通过 DMG 手动安装；Windows 沿用原有签名更新方式。项目协作服务需同步升级以支持身份恢复接口。Windows 凭据库、安装后的宿主接入及 macOS 升级后的钥匙串授权连续性仍需实机验证。

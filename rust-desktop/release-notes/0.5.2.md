修正咚咚连接与桌宠收起后的消息提醒。

• Windows 优先从正在运行的咚咚进程识别实际安装位置，修正自定义安装到 D/E 等盘符、注册表信息不完整时可能无法连接的问题，支持中文和空格路径。
• 咚咚会话读取失败时显示具体原因，避免所有失败都显示成“等待登录”。
• 收起或关闭桌宠悬浮窗口时，同时隐藏消息气泡、关闭独立消息卡及当前日程弹窗。
• 桌宠隐藏期间禁止消息气泡重新弹出；收起前尚未完成的弹窗请求失效，避免延迟弹窗突然出现。
• 收起不清除未读消息，仍可主动从设置或托盘查看咚咚消息。

平台：Windows x64、Apple Silicon Mac。
更新方式：Windows 保留签名自动更新；Mac 手动检查并下载 DMG 替换。

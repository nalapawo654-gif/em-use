READY WHEN YOU ARE

三步，开始一起工作。

01 / 安装

把伙伴请到桌面

Windows 运行安装程序；Mac 打开 DMG，将 EM Use 拖入「应用程序」。

02 / 连接

连接本机咚咚账户

先登录本机咚咚，首次启动 EM Use 会自动尝试连接并同步额度。也可在设置中选择「手动登录其他账户」；从旧版升级的手动账户会保留原登录方式，可主动切换为「使用咚咚账户」。

03 / 陪伴

选一只，换身装扮

在设置或托盘中选择桌宠。鼠标移入显示操作入口，可以拖动、缩放，也可以开启轻柔模式。

安装时出现“未知开发者”或发布者提示？＋

当前版本提供应用更新包签名，尚未配置 Apple Developer ID 公证或 Windows Authenticode 发行者签名，因此系统可能提示开发者身份未验证。请确认安装包来自本页；macOS 可在尝试打开后按系统提示进入「系统设置 → 隐私与安全」处理。公司设备请遵循组织的软件安装规则。

已经安装过了，怎么更新？＋

Rust 版会自动检查新版本，也可以在设置或托盘中手动检查。检查和下载需要能访问本页所在的内网服务器，确认更新后再安装。旧 Electron 版首次切换到 Rust 版，需要手动安装并重新登录。

它支持哪些额度账户？＋

当前连接东方财富 AI 云平台的每日额度。EM Use 不提供额外额度，也不是通用的所有 AI 平台余额工具。页面上的宠物画面使用演示额度，实际数值以你登录后的账户数据为准。

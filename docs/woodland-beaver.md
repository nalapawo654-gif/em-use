# 林间海狸鼠：角色与互动

2026-09-10 · 基于用户提供的《海狸鼠.png》。公共行为遵循 [桌宠基础交互规范](desktop-pet-interaction-standard.md)。

## 视觉与额度

暖棕色毛发、大门牙、扁尾巴和草帽保留参考角色特征；桌面端只呈现角色、树木、局部草地与额度木牌，透明窗口、默认隐藏常规操作，hover 和键盘焦点时显示。浏览器补充状态和玩法展示，全部明确为演示额度。

金额继续采用共享人民币额度，而非设计图的 Token 数字。树木是额度状态的视觉表达，送木头等互动不修改余额或恢复树木档位；未知额度显示“—”。

| 范围 | 角色 | 树木 |
| --- | --- | --- |
| >75% | 元气满满，眉眼舒展、嘴角上扬 | 完整粗树干 |
| >50%，≤75% | 放松闭眼，轻松啃树 | 啃去约四分之一 |
| >25%，≤50% | 半眯眼、用力坚持，开始伏低 | 啃去约一半 |
| >20%，≤25% | 疲惫眉眼、蓝色汗带和汗滴，身体伏低 | 啃去约四分之三 |
| >15%，≤20% | 眼睛几乎闭合、更多汗滴，明显低伏 | 只余约一成支撑，近乎啃断 |
| ≤15% | 趴下休息 | 倒木与树桩 |
| 未知 / 不可用 | 中性待连接外观 | 不将形态当作真实额度 |

2026-09-10 补充参考修正：树干以粗壮、明显高于角色的比例呈现，角色占窗口的尺寸从原来的 60% 调整为 48%，树的区域扩为 55% 宽 / 80% 高；素材保持宽高比，不把树木压成小盆景。表情、伏低程度、啃树节奏与树木损耗都使用同一额度档位。主动互动保留当前额度表情，结束后仍恢复该档位的日常状态。

主场景和六档缩略预览共用 `BeaverVisual`、同一套表情图集与树干图集；缩略图仅裁取同一个构图，不能另用与真实桌宠不同的状态图。天气装扮是独立偏好，不因额度变化强制切换。

## 常态与动作衔接

常态持续面向树干啃树：头部前探、嘴部咬合、双爪扶树，咬点出现少量木屑。>15% 各档都啃树，额度越低节奏越慢；≤15% 和主动休息仍趴下。未知额度使用中性日常动作，木牌保持“—”。轻柔模式停止循环咬合、摇尾和木屑，保留清晰的互动姿态。

互动开始约 0.8 秒内从树边退开，随后执行动作，短动作最后 0.7 秒放下道具并回到树边继续啃。身体、头、嘴部、尾巴、前爪和手持道具在同一画布按同一时间轴渲染；面杯和瓶口使用嘴部位置，球与前爪使用同一个运动位置，不能只让整张角色图或道具晃动。取消立即清除道具、恢复常态；新动作替换旧动作。动作结束不改变额度。

## 角色专属玩法

| 入口 | 手势 / 反馈 | 完成与重入 |
| --- | --- | --- |
| 主体 / 摸摸它 | 点击，离开树干抬头、摇尾、收起前爪并显示爱心 | 2.6 秒结束，新动作替换 |
| 梳毛 | 按住毛发范围来回梳动，刷子跟手，抬头、摆尾和前爪响应、进度反馈 | 按归一化有效移动距离累计 1.5 完成，单次输入上限 0.12；静止不增长，完成庆祝；再次进入重新开始 |
| 喂面 | 点击，退开抱碗，低头吸面、嘴部咀嚼 | 5.6 秒结束 |
| 喝水 | 点击，退开举瓶，瓶口贴嘴，抬头吞咽 | 5 秒结束 |
| 送木头 | 点击，退开抱住木头，咬合并掉落木屑 | 5.2 秒结束，不恢复额度 |
| 丢球玩耍 | 点击，低头追球，前爪跟球的位置伸出、收回 | 6.2 秒结束 |
| 收集树叶 | 前爪伸出接叶，点击三片独立叶子，每片只能计数一次 | 集齐庆祝，18 秒未完成则退出 |
| 小鸟来访 | 点击，抬头迎接小鸟、伸爪，伴随停留、离开与音符反馈 | 5.2 秒结束，没有自动播放声音 |
| 歇一会儿 | 点击，暂时趴下休息 | 7 秒后恢复额度对应姿态 |
| 和它说话 | 输入短句，本机预设趣味回应 | 提交后回应；不连接聊天模型或发送内容到外部 |
| 布置营地 | 点击添加 / 收起帐篷 | 本机保存，场景切换与重启后保留 |
| 更换标语 | 选择三条短句之一 | 本机保存，独立于额度 |
| 拍照 / 生成分享图 | 隐藏界面操作、调用公共截图与保存对话框 | 桌面保存 PNG；用户可自行发送，不自动发布到外部平台 |

不添加统一“清洁”动作。梳毛使用移动距离，不复制鱼缸的玻璃覆盖计数；没有自动梳毛入口。所有主要玩法可由结束按钮或桌宠容器内 Esc 取消，新玩法清理旧状态。梳毛期间场景优先处理互动手势，松开及完成后抑制误触摸摸；退出后恢复窗口拖动。

未设计双击玩法。短动画在轻柔模式下减少运动并缩短至不超过 1.8 秒，保留结果和手动玩法入口。

## 装扮与共享接入

五种天气主题装扮：晴天草帽、雨天雨帽与完整雨衣、下雪绒帽与红围巾、刮风护目镜帽与橙围巾、夜晚头灯帽与背心。它们是用户选定的装扮，不读取实际天气，不展示参考图中的虚构实时温度和时间。公共白天 / 夜晚 / 自动设置控制场景光线，装扮独立保留。

嘴部直接在头部轮廓内轻微形变，不叠加独立下巴。五套帽子与六档表情分别合成完整头部素材，耳朵遮挡、帽檐接触阴影和毛发衔接都在同一图层内；雨衣 / 背心 / 围巾与躯干采用一体穿戴素材，随身体共同变换，头部和前爪按真实遮挡顺序覆盖。休息使用五套完整穿戴趴姿，不把站姿衣物叠到背部或脸上。衣橱缩略图复用对应穿戴头部。树木保留 0 / 25 / 50 / 75 / 90 / 100% 啃损分档，50% 剩余额度对应约一半的缺口。当前素材与生成提示见 [integrated-generation.md](../public/assets/beaver/integrated-generation.md)；[fit-generation.md](../public/assets/beaver/fit-generation.md) 为旧独立服饰方案记录。

新增 `scene: beaver`、`beaverSkin`、`beaverCamp`、`beaverMotto`。旧设置默认仍为鱼缸，牛马与鱼缸的装扮不被覆盖。场景入口接入浏览器、设置和托盘，共享额度、认证、窗口手势、缩放、设置校验、穿透与托盘生命周期。

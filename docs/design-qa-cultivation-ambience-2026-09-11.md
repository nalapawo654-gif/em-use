# 仙鹤、香炉和仙境衔接验收

## 实现

沿用现有图集，通过运行时裁切分层给仙鹤加入翼部运动及往返飞行。香炉遮住原图静止烟气，改为曲线烟段动画。所有状态共用当前组件的有效时间，不新增独立定时服务；暂停、手动互动、随机事件和轻柔模式具有明确优先级。

浮岛 / 天气 / 荷叶一起渐变，功法切换先淡出再淡入。背景丹炉与星盘在中性奇遇中保留，事件专属法器接管时才收起。面板不再卸载和重放奇遇开场。人物上一轮的固定尺寸和坐姿保持不变。

## 浏览器

- 普通修炼实际播放停歇、起飞与上方飞行，翅膀和烟气独立运动；只有一只仙鹤。点香增强同一炉身的烟气，结束后恢复。
- 云海切荷塘、再切观星，过渡中存在两个环境层，结束后只保留一个。雨境仙鹤回到台边；夜境烟色 / 光照跟随变化。
- 八种奇遇逐一点击预览并检查释放阶段：每次只有一只仙鹤；丹成 / 炸炉期间普通香炉 opacity 为 0 且 disabled，常态功法效果收起。
- 炼丹中的灵兽来访保留背景丹炉：道具 opacity 为 0.75，火焰为 0，动画处于 paused。
- 面板暂停检查：奇遇有效时间保持 1640.1ms，节点仍是原节点；关闭后继续至 1937.2ms，没有从头开始。
- 300 / 190px 组件截图已保存；轻柔模式烟气没有动画，仅保留一条 opacity 0.25 的静态曲线。
- 本轮浏览器没有页面 JavaScript 错误；开发服务器的 favicon.ico 存在与功能无关的 404。

# 电池人 · 桌角健身俱乐部

公共操作遵守 [桌宠基础交互规范](desktop-pet-interaction-standard.md)。本角色以用户的 `电池人.png` 为视觉参考，使用分层圆柱身体、两条手臂、两条腿、运动鞋和实时表情；不使用参考图中的固定百分比或互动加额度规则。

## 外观与额度

透明窗口中保留电池人、位于两侧的收纳垫和小音箱等少量场景道具、台词与额度牌。浏览器另有完整说明和状态预览。

| 共享剩余额度 | 常态 |
| --- | --- |
| >75% | 开合跳、原地跑、高抬腿、太极、健美操、瑜伽轮换，幅度最大 |
| >50%–75% | 轻快慢跑、太极、健美操、瑜伽轮换 |
| >25%–50% | 慢举哑铃，喘气、出汗 |
| >10%–25% | 坐低拉伸，小幅抬手 |
| >0%–10% | 蹲低扶地、缓慢呼吸 |
| 0%及以下 | 横躺休息，不自主健身 |
| null / 非有限值 | 中性等待，显示 —，不伪装满电 |

stale 保留上次数字并显示“数据待更新”。连接、未登录、过期、跨日、无权限和不可用沿用共享状态。角色电量代表平台额度，不是电脑电池。品牌皮肤不改变额度色条与分档。

## 独立玩法

所有玩法都可从顶部玩法菜单进入，常用项还有悬停工具条和浏览器演示入口；场景右键打开玩法。主体轻点为击掌，休息时轻点起床；不设计双击、拖拭或自动完成。

| 动作 | 手势 / 道具 / 反馈 | 完成与退出 |
| --- | --- | --- |
| 陪练举铁 | 进入后按“举一次”，每次独立完整举起/放下哑铃计一次；间隔 900ms，6 次完成；低电量改为坐姿轻举 | 真实点击累计，等待不会计数；完成展示奖章 1.8s 后回常态；结束 / Esc 取消；再次进入重新计数 |
| 跳绳 | 绳圈旋转、身体与鞋子同步离地；电量低时改为小幅跨绳，0% / 未知拒绝健身并提示休息 | 6s 自动结束，结束 / Esc 随时取消 |
| 接上充电 | 场景侧边充电座接线到电池顶部；沿线电流、触点光环与闪电反馈；不含水瓶和喝水动作 | 6.4s 自动结束；0% / 未知也允许，结束回真实额度姿态；不改变额度数字 |
| 打一套太极 | 云手绕圆、左右重心转移、宽马步；电量越低幅度越小 | 12s 自动结束 / Esc 取消 |
| 跳健美操 | 左右踏步与交替过顶伸臂，脚底交替支撑 | 10s 自动结束 / Esc 取消 |
| 做会儿瑜伽 | 此时才展开平整瑜伽垫，树式单脚平衡过渡到侧身伸展；手掌在头顶上方 | 14s 自动结束 / Esc 取消，退出收起垫子 |
| 擦擦汗 | 毛巾轻拍额头、汗滴消退；点击即执行，非拖拭 | 3.2s 自动结束 |
| 击掌打气 | 主体轻点或菜单按钮；抬手、笑脸、爱心 | 2s 自动结束，不增加额度 |
| 躺平休息 | 躺到枕头旁，闭眼 Zzz | 持续；“起床”、主体轻点或 Esc 恢复真实额度姿态 |

一次只保留一个主要玩法；替换清理上次进度、道具与完成状态。额度下降至 0% / 未知时中止健身，其他陪伴动作可以继续。页面隐藏取消短动作，保留主动休息；卸载清除帧循环和监听。轻柔模式静态呈现当前动作与计数，不持续跳动。

## 装扮与场景

独立设置字段：`batterySkin`（classic / nanfu / xiaomi / duracell / byd / catl），`batteryRealm`（office / balcony / overtime / weekend）。默认元气绿与工位健身。皮肤名称为元气绿、北孚、大米、铜霸王、A亚迪、您德时代；A亚迪外壳英文为 AYD，其他趣味款使用对应中文。官方 Logo 图片已删除。存储 ID 保持兼容，旧装扮选择不会丢失。

场景道具使用同一落地基线：角色运动区居中；小音箱、盆栽或充电座位于左侧；完全卷起的垫子位于右侧。普通动作不踩半卷垫，瑜伽时才展开平整垫子。休息时移开常态道具并将枕头置于头部下方。鞋底根据旋转后的支撑脚计算落地坐标，显式跳跃才离地；轻柔模式保持落地姿态。没有台灯或水瓶渲染。

常用工具条为举铁、充电、太极、健美操、瑜伽、休息；九种玩法均可从顶部菜单及浏览器玩法区进入。夜色仍跟随公共昼夜设置。

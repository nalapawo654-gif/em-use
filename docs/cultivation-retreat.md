## 仙境

独立字段 cultivationRealm：sunny 云海仙山、rain 荷叶听雨、night 观星悟道、thunder 雷霆护体、tribulation 特效渡劫、enlightened 重回巅峰。仙境仅改变局部环境、法阵和天气；不把雷劫效果解释成余额变化。昼夜仍由公共 theme 控制；轻柔模式停止循环动效，保留进度与完成提示。保存途径为共享 api.settings + validateSettings。

标准 440 / 紧凑 300 / 迷你 190：小尺寸保留顶部玩法、仙境、设置、收起按钮；常用六工具可隐藏，更多面板可滚动，结束按钮常驻。面板互斥、移出不关闭；面板和动作占用时隐藏四角手柄。真实原生和账户验收另记。

## 第二轮：随机修炼与百宝衣橱

用户要求修炼场景和动效随机化。默认开启 cultivationRandom：每 24–42 秒从六境与四种修炼中各抽取一个不同于当前的项目；打开面板、拖窗、进行手动互动和页面隐藏期间暂停倒计时。恢复可见后不追赶后台次数。可手动“换一段机缘”，关闭随机后固定所选仙境；固定模式修炼方式仍可用按钮换一段。切换场景和手动选择通过共享设置保存，随机过程不频繁写设置。

修炼分吐纳（掌心灵珠、呼吸光环）、御剑（飞剑绕行、剑气弧线）、炼丹（丹炉、火焰、丹丸升起）、悟道（星盘、经卷、星轨）。动作采用运功姿态、收势姿态与呼吸位移，叠加独立法器层；零额保持疲惫原貌并呈现温和静养，未知态不暗示满额。手动互动优先并暂时收起修炼法器，结束后恢复当时修炼。

新增四套完整角色图集（经典云岚、青霄剑修、紫微星官、朱雀锦衣），每套含四个额度表情和两种运功姿态。独立保存 cultivationSkin。新增可选配饰与随身宝物：莲花冠、星月冠、桃花簪、灵葫、玉佩、锦囊；保留不佩戴选项。角色和道具资源加载失败有可见反馈。

六境除天气色调外切换浮岛物料：云海石台、荷塘浮屿、观星石台、雷纹石台。白天夜晚仍由公共主题控制。轻柔模式保留当前法器与修炼姿态，停止循环、粒子移动和随机自动轮换；手动换景仍可用。

## 第三轮修正 · 2026-09-11（以本节为准）

- 人物沿用四套六姿态图集，新增连续网格运动渲染：独立运掌、衣袖摆动、胸口呼吸、发梢轻摆；配合六秒收势 / 结印 / 展掌节拍和明显的升降。单个 WebGL 网格每秒最多绘制 30 次；关闭页面、面板、拖窗与轻柔模式暂停绘制，卸载释放纹理、缓冲和动画。WebGL 不可用时回退图集姿态与 CSS 动画，不留下空白。
- 人物、浮岛与法器以同一石台平面重新布局。香炉与仙鹤缩小并落台，增加坐姿接触阴影和前景薄雾，调整四种功法的法器尺寸。发饰与随身物缩小；递茶、仙桃、梳子绑定到人物容器，角色位移时一起移动。递茶 / 仙桃使用合掌姿态；木鱼带音波，点香带向上散开的烟，天地人按钮同步点亮场景符印。
- 渡劫和顿悟从常驻仙境选项改为修炼中的独立短时随机奇遇。常规仙境保留云海、荷塘、观星、雷霆四类；旧 tribulation / enlightened 设置兼容映射至雷霆 / 云海。首个奇遇在 10–18 秒有效修炼时间内到来，此后每次结束后等待 26–46 秒；加权随机降低重复概率，不强制交替。
- 每次奇遇共 10 秒：2.2 秒起势、5.2 秒释放、2.6 秒收势。渡劫包含劫云、分支落雷、护体罩、符印和地面冲击；顿悟包含金色光柱、法轮、道法自然文字、上升花瓣与莲座。特效与人物、石台共享坐标；局部光效不做整窗白屏闪烁。
- 奇遇期间冻结原功法与换景倒计时，结束后至少保留原功法 8 秒。互动、面板、拖窗、页面隐藏暂停奇遇；手动互动期间收起奇遇效果，结束后从原时间恢复。Esc 取消当前奇遇，换机缘和修改随机 / 仙境选项清除旧事件。卸载无延迟事件遗留。
- 关闭随缘修炼后不自动换境或产生奇遇。轻柔模式不产生新随机奇遇，已有事件保留静态视觉与阶段提示并按时结束。低额、零额、未知仍保留对应表情，不被事件改为满额姿态，所有效果都不改变真实额度。
- 浏览器完整预览额外提供“预览渡劫 / 预览顿悟”以便查看；原生窗口只在修炼中随机发生，无常驻特效演示按钮。

## 第四轮 · 日常修炼插曲（2026-09-11）

用户确认补齐打坐犯困、飞剑失控、丹成 / 炸炉、灵兽来访和仙友传书，共六个新增随机事件。公共操作规则继续使用基础交互规范；互动和事件均不改变真实额度。

| 事件 | 随机发生条件 | 演出与完成 |
| --- | --- | --- |
| 打坐犯困 | 吐纳 / 观星 | 闭目点头三次、身体渐歪，惊醒后坐直；9 秒 |
| 飞剑失控 | 御剑 | 飞剑乱窜、仙人左右躲闪，再结印召回；10 秒 |
| 丹成异象 | 炼丹 | 炉盖浮起、金丹升空，仙人接丹收袖；10 秒 |
| 炼丹炸炉 | 炼丹 | 炉身抖动、盖子弹起、烟雾扩散、暂时熏黑脸，再抖袖清去；9 秒 |
| 灵兽来访 | 任意功法 | 现有仙鹤衔灵草踱近，仙人俯身抚摸，收下灵草后仙鹤回原处；11 秒 |
| 仙友传书 | 任意功法 | 折纸鹤飞入，展开书信，仙人低头阅读，再折鹤飞走；12 秒 |

每段包含起势、主体和收尾三个阶段，阶段比例沿用 22% / 52% / 26%。依据当前功法过滤后按权重抽样，并排除上一事件，避免连续重复。渡劫 / 顿悟权重分别为 1 / 2，日常事件权重更高；各功法的归一化概率不同。事件至少在当前功法修炼 4 秒后发生，首轮等待 10–18 秒、结束后等待 26–46 秒的节奏保留。

一次只运行一个事件。所有事件自动完成，也可点击“收心”或按 Esc 结束；取消不触发奖励、额度变化或延后补发。手动互动、面板、拖窗与页面隐藏暂停事件，恢复时接着原进度播放。新事件的角色、法器和临时物件统一使用有效事件时间驱动，暂停恢复不会重放开场。局部组件以每次事件序号重新挂载，连续预览相同事件也会重新开始。

四种衣装复用原图集；纸鹤和灵草为独立矢量物件。炸炉的灰痕只叠加在脸部，随收尾消失，不替换成零额度图集帧。低额、零额、未知的表情始终保留。轻柔模式不自动产生事件，手动预览保留静态道具与阶段提示；暂停、退出和完成路径不变。

完整浏览器预览提供八种事件的演示按钮；预览专属事件会先匹配对应功法。桌面端仅由随机修炼自然触发，提供当前奇遇的“收心”按钮，不增加常驻事件菜单。事件消失后临时物件销毁，现有仙鹤、香炉与常态功法恢复。

## 第五轮 · 修炼动作稳定性（2026-09-11，以本节覆盖第三轮的人物运动设计）

用户反馈修炼时人物忽大忽小。实际容器没有缩放，但原网格将双侧衣袖向外拉伸，同时人物以最高 2.6cqw 上浮，造成膨胀、收缩和离地的观感。移除这些横向撑开、胸口拉伸和整个人浮动的常态动画；修炼时坐姿容器和接触阴影固定。

继续播放收掌、结印、展掌的原画姿态，使用受限的肩关节旋转带动外侧前臂与袖口。脸部、躯干中轴和盘腿下摆的网格保持不动；局部运动最大位移小于人物宽度的 1.2%。四套图集按脸部中心做静态水平平移校正，不按动作缩放图片。WebGL 和图像回退采用同一校正，回退先裁切单帧再平移，避免漏出相邻格子的袖口。

保留八种随机奇遇、手动互动和原有额度语义。特殊事件原有的躲闪、点头、顿悟升起等叙事动作仍按事件触发，不作为普通修炼循环。

## 第六轮 · 仙鹤、香烟与场景衔接（2026-09-11）

- 仙鹤沿用原图的羽毛与身体，运行时分层转动翅膀。32 秒常态周期包含 7 秒停歇、起飞、上方往返和落台，飞行段约 17 秒；在头顶上方穿行，避开正脸和额度区域。晴天 / 观星可飞，雨天、雷境、御剑和奇遇期间让出空域。
- 事件或手动互动到来时，空中的仙鹤先沿上方回到右侧再落台。灵兽来访接管同一只仙鹤的踱步，不生成第二只；落地阴影随踱步移动，飞行时变淡。原有轻点问安与共享拖窗规则保留。
- 香炉保留同一炉身，遮掉原画中静止的烟，使用三段细烟沿曲线交错上升。点香时增强烟气和炉口微光；雨、夜、雷境改变烟的偏向或颜色。炼丹时由丹炉接管同一区域，避免重复摆炉。
- 浮岛、天气和荷叶以 1 秒整体交叠渐变换境；人物尺寸与坐姿不参与过渡。四种功法以 0.45 秒淡出 / 淡入切换。重事件压低环境天气，结束后恢复。
- 奇遇期间暂停常态功法动效；炼丹 / 观星遇到来访、传书等事件时保留丹炉 / 星盘作为背景，收起火焰、丹丸与粒子。丹成、炸炉、飞剑失控则由事件道具接管。普通功法动效在事件结束后从暂停处恢复。
- 面板打开时保留当前奇遇节点并暂停，关闭后接着原进度播放。轻柔模式停飞，保留单缕静态烟；隐藏页面、拖窗、面板及卸载清理继续遵守公共规范。

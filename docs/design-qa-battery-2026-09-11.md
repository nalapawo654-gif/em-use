# 健身电池人验收 · 2026-09-11

## 实现

- 新增健身电池人场景，接入浏览器选择器、公共设置与 Electron 托盘菜单；复用账户、额度、窗口手势和设置校验。
- 六档额度加独立未知态，自动开合跳 / 原地跑 / 高抬腿 / 慢举铁 / 坐姿拉伸 / 扶地 / 横躺。
- 举铁六次、跳绳、接上充电、擦汗、击掌、持续休息、太极、健美操、瑜伽；动作只改变视觉。
- 元气绿、北孚、大米、铜霸王、A亚迪（AYD）、您德时代六款；使用原创趣味字标，五个官方 Logo 图片已删除，运行时不再请求 Logo。四种局部道具场景，支持公共昼夜与轻柔模式。
- 图集与提示词保存在 [素材目录](../public/assets/battery/generation.md)。运行时色键分离，并明确首行身体与第二行四肢的取图间隙，避免把金属底边当作鞋子的一部分。六款身体、左右手、左右鞋与实际关键姿态均已查看。

## 本轮调整

- 鞋底按旋转后的实际落点对齐地面，跳跃才离地；音箱与卷起的垫子移到活动区两侧。瑜伽时单独展开平垫。
- 台灯换成音箱；喝水换成充电座、接线、流动光点及闪电，归零也可充电，真实额度不变。
- 太极采用宽步重心转移和云手；健美操左右踏步举手；瑜伽包含树式平衡与侧伸展。高电量闲置轮播，低电量降强度，归零拒绝训练。

## 实际浏览器验证

Playwright 驱动独立 Chrome 会话，使用本地 Vite 应用。根页面为浏览器演示数据；`battery-native.html` 使用显式模拟的 `window.emUse`，不调用真实账户。

- 未悬停操作区隐藏，悬停显示；面板在移出后保持；键盘焦点能显示操作区。
- 容器 Esc 关闭面板与取消动作；衣橱 / 玩法 / 详情共用互斥面板状态。
- 举铁等待不会增加次数；动作进行时按钮禁用；六次完整动作后展示奖章，自动恢复。前后额度不变。
- 充电、擦汗、击掌、跳绳可开始和取消；休息提供持续起床入口。
- 归零拒绝训练并解释，未知显示 —。过期、同步中、无权限、不可用、未登录分别显示对应状态；stale 保留数字并明确待更新。
- 190 / 300 / 440 px 布局：菜单可达、衣橱能滚动选择并关闭、休息可退出；面板期间缩放手柄隐藏。
- 模拟桥接：轻点触发击掌，跨越阈值的拖动调用公共手势并抑制点击；四角与 Ctrl 滚轮路由到公共缩放；设置与收起调用共享 API。
- 皮肤与场景切换保存，切到其他桌宠再切回来仍保留；浏览器重载保存选择。白天 / 夜晚、轻柔模式已查看。
- 浏览器只出现现有 `/favicon.ico` 404，未见电池人运行错误或素材加载错误。

本轮补充验证：浏览器玩法 / 字标 / 充电 / 轻柔模式共 27 项检查通过；190 / 300 / 440 px 模拟窗口、状态与共享手势共 25 项检查通过。太极、健美操、瑜伽确认画布随时间变化、Esc 可退出；零电量充电完成后恢复横躺，额度不变。

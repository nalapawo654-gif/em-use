# 充气牛马：场景与交互计划

> 历史设计计划。后续开发以 [桌宠基础交互规范](desktop-pet-interaction-standard.md) 为公共交互依据；本文的完整草地背景与估计动作时长不代表当前实现。当前桌面呈现采用透明背景和局部场景物件。

## 目标与视觉

基于用户 2026-09-10 提供的设计板，新增与「额度小鱼缸」并列的「充气牛马」场景。保留蓝天、草地、木栅栏、奶油色充气玩具、棕色鬃毛、金色铃铛和木牌额度。桌面窗口呈现设计板左侧的完整宠物场景；浏览器预览补充右侧的状态、互动、动作和换装展示，全部可操作。

场景切换置于浏览器顶栏和桌面设置。鱼缸与牛马分别保留装扮选择，切换不改变账户、额度、昼夜、窗口尺寸或桌面偏好。旧设置默认仍显示鱼缸。沿用现有字体和 Phosphor 图标。

## 额度与日常状态

| 剩余额度 | 形态 | 日常反馈 |
| --- | --- | --- |
| 大于 60% | 饱满站立 | 轻柔呼吸、开心晃动、偶尔摇尾 |
| 大于 25%，不超过 60% | 略瘪 | 降低弹跳幅度，偶尔叹气 |
| 大于 0%，不超过 25% | 明显瘪、趴下 | 慢呼吸，提示留意剩余额度 |
| 0% | 瘫软休息 | 停止活跃动作，等待真实额度恢复 |
| 未登录或不可用 | 待连接 | 木牌显示「—」，不伪造可用额度 |

木牌使用现有真实额度单位 ¥，不照抄参考图的 GB。浏览器状态卡使用 100 / 50 / 20 / 0 的明确演示数据。真实额度恢复时自动播放短暂充气反馈；互动、手动充气不改变真实额度。

## 用户动作

| 触发 | 可见动作 | 结束与边界 |
| --- | --- | --- |
| 喂草 | 草料靠近嘴边、低头咀嚼、满足反馈 | 约 3 秒，回到额度对应状态 |
| 喝水 | 水桶出现、低头喝水、水滴反馈 | 约 3 秒，回到日常状态 |
| 单击 / 摸摸 | 轻轻晃动、爱心、摇尾 | 约 2 秒；键盘 Enter / Space 同样可触发 |
| 清洁 | 刷子跟随拖动、泡泡、可见清洁进度 | 支持拖擦和「自动清洁」；完成庆祝，可随时取消 |
| 玩球 | 足球滚动、宠物探头 / 踢球 | 约 4 秒，额度低时使用轻柔动作 |
| 驱蚊 | 蚊子绕飞、尾巴摆动赶走 | 约 3 秒，自动结束 |
| 双击牛马 | 站立 / 趴下切换 | 姿态可持续；低额度优先保留休息形态 |
| 动作卡 | 摇尾、打盹、抖一抖、休息、充气 | 每个动作均有动画、提示与退出路径 |

新动作替换旧动作，Escape 和结束按钮随时返回日常状态。切换场景时清理动画、定时器与指针捕获。拖动桌面窗口优先按现有 5px 阈值识别，拖动后的点击不触发摸摸；清洁时拖动只擦拭，不移动窗口。

## 换装与材质清单

五种装扮：经典款、打工人（领带公文包）、摸鱼款（墨镜度假衫）、酷黑款、粉萌款。使用同一角色、视角和光照制作独立素材，昼夜通过场景氛围调整。

生成并纳入项目的物料：

1. 草地场景背景：蓝天、远景、矮木栏、近景草地；不包含宠物、文字和按钮。
2. 经典牛马四状态图集：饱满、略瘪、明显瘪、瘫软；统一格位、透明底。
3. 另外四种装扮的四状态图集：列为额度状态、行为共用同一套动画。
4. 互动道具图集：草料、水桶、刷子、足球、手掌、蚊子、打气筒、空白木牌；动态额度由界面渲染。

素材使用内置 imagegen 生成，保留生成提示和来源说明。真实宠物、场景和道具使用栅格物料，UI 控件用现有图标库；不拿截图整块充当可交互界面。

## 实施与验收

先完成物料，再接入共享设置、持久化校验、场景组件、状态机和预览展示。复用当前 Vue / Electron 工程，不增加新的登录或额度接口，不打安装包。

验收覆盖：新旧场景互切、五种装扮、四档额度及未知状态、六个互动、双击姿态、自动清洁、取消 / 重入、昼夜、轻柔模式、标准 / 紧凑 / 迷你窗口。运行类型检查及相关单元测试；在浏览器实际操作并截图比较。浏览器 fixture 与原生 OS 手势验收分别记录。


## 2026-09-10 用户反馈后的修订

- 客户端以桌面为背景。去掉天空、完整牧场图片和外层有色卡片，只保留角色脚下的一簇草地、额度木牌与小控件。
- 主角色改为独立躯干、头部和尾巴。眼睛、眉毛、嘴巴在头部坐标中绘制，跟随头部旋转。
- 喂草：看向草料、俯身、咬住、循环咀嚼并消耗草料、缓缓抬头恢复。
- 喝水：水桶落地，前半身俯下，嘴靠近水面、嘴部周期收缩与水纹、抬头恢复；不让桶跟随嘴浮动。
- 驱蚊：视线偏向蚊子、皱眉、两次甩尾，蚊子再飞走，恢复轻松表情。
- 摸摸/开心：眯眼笑、抬头迎手、摇尾；清洁时配合表情。踢球改为前蹄局部连续变形，睡觉闭眼，抖身有头尾错相，充气有身体体积变化。
- 每次互动都使用准备、执行、恢复阶段，共用时间线并平滑过渡。减少动态效果时停用连续绘制，动作仍可结束，额度始终来自原接口。
- 五种皮肤均接入新表情。摸鱼款主角色移除遮住眼睛的墨镜，以便看到动态眼神，保留草帽和花衬衫。

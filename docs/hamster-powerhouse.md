# 仓鼠动力机房 · 角色方案

更新：2026-09-10。依据用户原稿 [hamster-original.png](design-references/hamster-original.png) 及原客户端遮挡截图，遵循 [桌宠基础交互规范](desktop-pet-interaction-standard.md)。账户、额度、设置校验和窗口手势继续共用。

## 构图与素材

透明正方形悬浮窗。额度位于左上，跑轮与仓鼠居中偏右；左下监工猫、底部瓜子杯与瓜子、右下发电机及电线组成机房周边。夏日增加小风扇。无常驻矩形房间背景。常规操作悬停/键盘焦点显示。

`src/hamster/layout.ts` 为场景布局的百分比来源。主体画布到窗口高度78%结束，周边到80%结束；互动提示专用底部82–99%区域。动作期间工具行与状态行让位，不在仓鼠脸上叠提示。190px下保留短提示、跑轮圈数与结束/醒来按钮，金额在详情中查看。睡眠、低额度姿态往左收拢，避开发电机。

根目录设计板含完整的道具、服饰方向，但原客户端仅接基础仓鼠、跑轮与被子。新增独立素材：`props.png` 十二件道具、`wardrobe.png` 十二件服饰、`dressed/*.png` 七套完整穿着的开心/疲惫动作帧。素材来源、实际提示词、裁切坐标见同目录生成记录。品红底在 Canvas 加载时去除，物件独立绘制，数值与文案均由界面显示。

## 表情、跑步与衣橱

额度 >60% 活力满满，>10% 疲惫流汗继续跑，>0% 趴下休息，0% 盖被下班。未知值使用静止中性姿态与 `—`；其他不可用原因沿用共享状态。只有 ready/stale 可展示当前/上次余额；stale 标明“数据待更新”。数值单位人民币 ¥，不套用原稿中的 Token 数量。

跑轮主体与支架分层，支架不转。开心与疲惫各六帧，分别90ms/120ms切帧；小脚掌、短腿、步幅收在身体下方，所有帧按脚掌落点对齐轮面，轮速也相应放慢。原生轻柔模式与隐藏页面停止持续绘制。动作结束回到当前真实额度对应姿态。

衣橱含经典、日班、夜班、雨天、夏日、冬日、节日。通过 `hamsterSkin` 独立保存，复用 `api.settings()` 与共享校验。衣服直接绘制进每张完整身体帧，不再叠独立帽子或裤子；跑步和喂食都保留一体化穿着；趴下或盖被时暂收衣服，选择仍保留。夜间是色彩主题，与所选装扮独立。

## 互动

| 名称 | 入口与动作反馈 | 完成 / 恢复 |
| --- | --- | --- |
| 喂瓜子 | 工具、玩法面板或瓜子杯；整身穿着的咬瓜子/咀嚼两帧 | 3.2秒 |
| 梳梳毛 | 工具或玩法面板；刷子来回轻梳 | 4.5秒 |
| 敲铃铛 | 工具或玩法面板；黄铜铃铛摇晃 | 2.4秒 |
| 逗逗猫 | 工具或玩法面板；蓝鱼逗猫棒，猫停止摸鱼看过来 | 4.2秒 |
| 递咖啡 | 工具或玩法面板；咖啡杯向嘴边倾斜 | 3.4秒 |
| 盖被子 | 工具或玩法面板；蓝色被子，停轮休息 | 持续；醒来、轻点主体或Esc恢复 |
| 逗跑轮 | 玩法面板、轮缘；点击轮缘或“转一圈”累计 | 6圈后提示0.9秒；180ms内重复输入不计数，无自动完成 |
| 摸摸 | 玩法面板或主体；身体轻轻舒展与提示 | 1.5秒；睡眠中轻点则醒来 |

短动作点击进入自动播放；没有需要拖擦累计的梳毛进度。所有动作都可结束/Esc取消，新动作替换旧动作并清掉旧道具、进度。衣橱、玩法、额度详情互斥，主动关闭后焦点回场景。互动和换装均不改变账户额度。

点击与拖窗沿用共享5px阈值及400ms拖后点击抑制；左侧轮缘命中区域避开主体，避免转轮误触摸摸。没有双击玩法。缩放、位置、托盘、穿透等公共能力不另建服务。

## 监工猫日常

猫使用独立的12帧表情图：打哈欠（嘴张开、眯眼、抬爪遮嘴）、趴睡（闭眼、脸靠在爪上、轻微呼吸和Zzz）、偷吃（把瓜子递到嘴边、咀嚼、心虚侧看）。纸箱底部保持固定。

常态42秒循环里穿插哈欠、趴睡和偷吃，夜间延长睡眠；轻柔模式停留在静态监工，主动选择动作仍显示该动作关键姿态。点猫依次触发哈欠、补觉、偷吃，玩法面板也有三个直接入口，分别2.6/9/4.8秒自动结束，可结束或Esc取消。结束后先回到监工，重新计时。

喂鼠鼠时猫会趁机嗑瓜子；铃铛和逗猫棒让它停下摸鱼。猫的三个主动动作不阻断鼠鼠日常跑步，不改额度；猫的自主表情不单独弹提示。隐藏页面/卸载后停止绘制与监听。

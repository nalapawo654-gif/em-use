# 修炼人物伸缩修正

实际复现中，440px 场景的人物容器始终为 211px，CSS 矩阵没有缩放，但普通修炼上浮达到 11.44px；旧网格将左右衣袖沿相反方向拉伸。对照四套原始图集还发现不同格子的脸部中心未对齐。

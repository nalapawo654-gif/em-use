## 追加：持续啃树与分部互动动画修正

用户反馈原版角色只是整图轻微晃动，常态没有啃树、互动缺少角色动作。本次用独立身体、头、下颌、前爪、尾巴替换条带变形；新增 renderer 同步身体与道具。常态持续啃树；喂面、喝水、送木头离开树干后抱住道具、进食，再恢复啃树；其他玩法增加相应姿态。零额度保留休息，轻柔模式保留静态动作反馈。

- 源码 / 测试：40/40 单元测试通过，涵盖正额度待机持续咬合、零额度休息、短动作准备 / 执行 / 恢复、吃面与吞咽、其他玩法停止啃树、轻柔模式；类型检查与生产构建通过。
- 浏览器：逐帧页核对 10 种模式的画布确实变化；检查五套装扮、吃面 / 喝水 / 木头的嘴与手持物接触、迎接小鸟和零额度帽子位置。帧差本身只证明画布变化，部位和接触位置由截图人工检查补充。
- macOS Electron：隔离、未登录测试资料下 26 项通过，包括实际加载新画布、无操作时持续动画、常规控件默认隐藏、7 种玩法的角色画布变化、吃面 / 喝水 / 送木头自然结束、其他玩法 Esc 退出、190 px 窗口、无渲染异常。记录：`output/playwright/beaver-motion-native-check.json`；截图前缀 `beaver-motion-native-`。
- 发现并修复公共状态订阅回调隐式返回 Vue Proxy 的问题，避免 Electron 在设置 / 状态推送时报告 `An object could not be cloned`；完整原生回归已重跑通过。
- 已查看用户当前客户端窗口，显示新的角色部件和持续动作。没有为此次验证重新登录或操作真实账户；自动化不证明 Windows、OS 指针拖窗、真实账户同步链路。

新增素材和完整提示见 [rig-generation.md](../public/assets/beaver/rig-generation.md)，动作方案见 [woodland-beaver.md](woodland-beaver.md)。此前验收记录不作为本次分部动作已经存在的证据。

## 浏览器实测

使用本地 Vite + Playwright Chrome，原生尺寸通过 `tests/fixtures/desktop.html` 的模拟桥接呈现。浏览器测试不等于真实 OS 验收。

- 发现并修复 WebGL 顶点 / 片段着色器精度不一致导致的链接失败。修复后实际渲染为 canvas（不是旧图集 fallback），时序截图记录真实运掌姿态和浮动。
- 使用固定随机输入让实际 100ms 调度器分别自然触发渡劫、顿悟，未直接注入事件状态。两者均完成起势、释放、收势并退回原功法；事件期间没有切换地面或衣装。
- 六种手动互动逐一点击并截图。互动期间常态法器收起，Esc 后恢复；错序符印不推进，按天地人完成后场景三印点亮；五次键盘梳动完成。
- 440 / 300 / 190 px 均检查场景、玩法面板、三印完成与结束入口；面板移出保持，关闭并移出后常规工具隐藏。迷你尺寸因隐藏副标题，自动化定位改用可见动作名后复验通过。
- 四套衣装分别以 100 / 50 / 10 / 0 演示额度检查，实际帧分别为 4 / 4 / 2 / 3；未知额度保持 — 和中性帧 0。白天经典衣装与夜间青霄衣装检查；迷你轻柔模式的角色变换与功法保持静止，仍保留场景和玩法入口。
- 完整浏览器预览的渡劫 / 顿悟按钮可用，1280 / 390 px 下无水平溢出。
- 修正云海 / 荷塘岛屿图集邻格碎屑、聚气灵珠遮脸、梳头提示遮脸，以及渡劫雨景的荷叶与劫云重叠。
